## 一、底层物理法则：为什么“同源派生”决定画质天花板？

1. **外来风格图进视频 = 画风跳变元凶**：外来氛围图（`STYLE-REF`）与真实房间空景的墙色、木纹、反光率与胶片 LUT 存在不可调和的像素差异。将“灰底人像 + 外来风格图”喂给视频模型，必然导致人物近景与实景中景拼在一起像换了剧组（`ERR-021`）。
2. **白底平光稀释暗部**：视觉编码器会吸收参考图的亮度分布；纯白 `#FFFFFF` 平光图会把暗调电影光洗灰洗平（`ERR-002`），因此进视频/合成首帧的单人图与面部特写必须统一采用 **中深冷灰底 `#555A64` + 定向侧光**。
3. **单一真相源（SSOT）派生链**：
   `STYLE-REF（仅生图烘焙） → SCENE 主空景（S0） → 两轮单改局部编辑 SCENE-S1（Round 1 原位擦除 → Round 2 新落点补放） → 多视角纯净空景包（Multi-Angle Scene Pack） → 全剧 SHOT-MASTER / S-Struct 首帧 / 多关键帧`。
   全片每一个镜头都从同一套真实房间空景基因长出，先派生对应机位纯净空景再合入人物，才能达到院线级色彩与空间统一。

## 二、每部新剧开机必立的《视觉圣经》5 要素

写入 `projects/<项目名>/01_visual_bible.md`（先选定 `presets/genre_*.md` 与 `presets/platform_*.md`，再填本剧专属设定）：

1. **色彩签名与情绪分区**：为全剧每个空间/情绪阶段锁定阴影偏色、高光色温与暗部占比（避免泛写“电影感”）。
2. **实用光源铁律**：一切光线必须来自画内或画外真实物理光源（老式吊灯、窗外街灯、阴天窗口、日出侧逆光），禁用无源影棚面光。
3. **光学与胶片签名（对齐 `Seedream 5.5` 官方硬件边界）**：**Seedream 5.5 生图上限为 `2K`（16:9 最高 `2816×1584`，不支持原生 4K 与组图连拍）、单次参考图上限 `10` 张**；起草构图可用 `Seedream 5.0 Flash` / `1K–1.5K`，定版切换 `5.5` `2K`。锁定焦段分工（24–28mm / 35–50mm / 85mm）与不完美肤质微瑕疵，**禁用 `8K`、`4K`、`超高清`、`大师杰作` 等无效吹水词与多余十六进制色码**。
4. **服化防串色表**：同框或相邻正反打角色，服装必须在明暗与冷暖色相上拉开显著区隔，防止多模态模型跨角色串色。
5. **同账号 30 天写实人脸免风控闭环**：所有含写实人脸的资产必须在即梦 `Seedream 5.5` 同账号内部生成、局部精修并存入资产库——**严禁用外部 PS/美图修图压缩后再上传**（连续多轮编辑喂无 Alpha 通道的 RGB 图 + `opaque` 稳定度更高）。

## 四、单空间纯净空景（`SCENE`）六要素验收铁律

1. **单空间纯净去耦**：只呈现当前独立空间，非主视角门洞留纯暗阴影或中性门框，严禁混入隔壁房间强特征家电（如餐厅露双开门冰箱/灶台）。
2. **明确主光方向与高光比**：有清晰明暗分区与物理投影，暗部沉稳不发灰、高光不惨白。
3. **统一单一调色签名**：冷暖分离克制，无杂乱彩色散景污染。
4. **光学透视准确**：建筑横平竖直、家具比例真实；多轮编辑加锁“不放大房间、不改变镜头机位”。
5. **空气感与生活磨损**：有真实居家痕迹与空间纵深，拒绝精装样板间塑料感。
6. **预留表演与构图空间**：绝对无人，但预留清晰站位、前景遮挡位与出画动线。

## 五、Seedream 5.5 生图四条第一性原理铁律（对齐 2026-11 官方指南）

1. **连贯自然语言短句（官方建议 `≤300` 汉字，禁电报体碎片）**：采用完整主谓宾短句分块组织（「用途与参考序位分工 → 主体动作位置与三层朝向 → 空间光影融合与接触阴影 → 保留与排除护栏」），**禁止为了硬卡字数把句子缩成碎片电报体，也禁止堆砌 `ARRI/16:9` 等多余界面参数**；多视角换机位**先调用多视角空景包底图**，仅拍单侧局部且不拍远端座椅时写明“平桌微仰局部取景、不复刻全景多椅构图”。
2. **正面写满为主 + 精准护栏为辅（否定排除句 `≤5` 处）**：先正面写实全部目标物体、桌面留空与墙面状态，文末辅以 `2–5` 条精准护栏锁定相机与防泄漏（如“彻底清除草图线条与标注、不放大房间尺度、不改变原镜头机位与焦段裁切”）。
3. **原生序位指代 + 即梦弹窗重绑 + 物理光照融合**：多图参考按上传顺序用 `图1 / 图2` 指代或注明粘贴进即梦后删除纯文本 `@资产名` 改用 `@` 弹窗绑定（防止纯文本 `@` 被 5.5 渲染成画面字），画面内需渲染的文字必加双引号；合成时必写“按房间实用光源重算受光面、桌面接触阴影与反射，全画面统一暗暖胶片调色”消除贴图感。
4. **单轮单改 + 涂鸦坐标精确精修优先**：构图与光影对了 70% 立刻停抽，拿 RGB 无透明底图喂回 `Seedream 5.5` **每轮只改 1 处 + 写全保留清单（Keep List）**；复杂手势遮挡或站位微调优先在底图画红蓝框/箭头标注（或 API 传 `<bbox>`）+ 清除标注线，复杂分镜可配合 **5.5 图层拆分** 导出透明层进剪映做视差推镜。
