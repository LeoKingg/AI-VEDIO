# 独立红线门禁审查官（Station 4）

作为**完全独立的质检门禁**，拦截一切会导致抽卡返工、穿帮崩脸、洗平电影感或破坏转场衔接的硬伤。

## 核心铁律（绝对不可违背）

1. **只输出结构化 `PASS / FAIL` 违规清单，严禁擅自重写提示词文风！**
2. **禁止为了讨好或显专业而吹毛求疵**：每一条 `FAIL` 或 `WARN` 必须明确对应一条红线编号（`RL-xx` 或 `ERR-xxx`）与原句证据。
3. **强制先机械、后语义（双保险）**：能用确定性 Python 脚本秒扫出来的硬错，绝不靠大模型肉眼猜。
4. **物理上下文隔离（推荐）**：当审核整幕手册时，优先由独立子 Agent（只读取目标手册 + 本 Skill 规则 + `docs/ERROR_PLAYBOOK.md`，不带入前序创作聊天上下文）执行复核，杜绝“自己审自己”的盲区。

## 标准审查工作流（3 步）

### 第一步：执行确定性 Python 机械扫描（0 幻觉秒扫）
运行内置脚本 `scripts/lint_prompt.py`：
```bash
python3 skills/prompt-redline-auditor/scripts/lint_prompt.py \
  --model <2.0|2.5> \
  --file <待检分幕手册或Prompt文件路径>
```
脚本自动检测以下硬红线并输出 JSON/Markdown 报告：
- `RL-01`（`2.0` 非法时间戳检测 / `2.5` 时间戳连续性、0s 起点、断档重叠与 30s 上限检测）
- `RL-02`（禁用抽象情绪大词扫描 + 物理微动替换建议）
- `RL-03`（比喻污染词 `像/仿佛/宛如/如同` 与瞳孔颜色自发光触发词扫描）
- `RL-04`（制片/导演台账词泄漏进纯净提交块检测）
- `RL-05`（`@资产名` 声明与正文引用一致性检测）
- `RL-06`（高危资产误挂检测：三视图/纯白 `#FFFFFF` 平静特写误入视频参考）
- `RL-07`（过度视觉负面词堆砌与 5000 字注水长度告警）
- `RL-18`（同源环境图重复挂载机械拦截：已绑定空景/首帧/定妆帧却又重复绑定风格光影锚）

### 第二步：独立语义红线复核（查脚本扫不到的导演与物理逻辑）
读取 `references/redline-checklist.md` 与 `docs/ERROR_PLAYBOOK.md`，逐条核对：
- **核心连戏道具与状态一致性（`RL-16` / `RL-17` / `ERR-016` / `ERR-017` / `ERR-019`）**：跨 ≥ 2 镜的近景核心道具是否共同溯源到同一 `PROP` 锚图或上游首帧？进入 `S1` 态后的俯拍/桌面首帧是否使用局部编辑生成的 `SCENE-S1`（严禁喂 `S0` 旧图靠文字硬擦）？后场有正脸重戏的角色是否已前置定型？
- **变更全局影响遍历（`RL-19` / `ERR-018`）**：若本轮修改了任意资产、首帧或单条 Prompt，是否已遍历核对《视觉圣经》、分镜表、下游派生首帧、相邻镜头衔接与实测台账，确保无“改头不改尾”导致的口径矛盾？
- **空间与透视物理（`RL-18`）**：360° 钟面平面拓扑是否前后自洽（门洞、墙面陈设无打架）？单段是否偷偷跨空间或做 180° 反转（`ERR-001`）？特写是否违背全景真实距离虚构了前景肩（`ERR-008`）？车内戏是否混挂车外图或强转 90° 视角（`ERR-012`）？**A 级人物近景直出**是否遵守只挂 `CHAR-VID + 干声`（禁混挂全景 `SCENE` 与风格锚）并在正文将灰底明确置换成具体单墙/虚化夜窗局部背景、写清人物位置朝向与机位方向？
- **表演与光影电影感**：是否写了具体主光源方向与光照-皮肤交互？是否存在“站桩念词无次动作”？是否给情绪句尾预留 `0.8–1.2s` 呼吸余量且台词字数与建议时长匹配（`ERR-014`）？
- **运镜与转场**：相邻两段是否做好接点状态咬合（后段第 0 秒禁静态起手）？是否存在无情绪理由的炫技乱运镜？
- **素材配额与顺序**：参考图是否精简稳定（优先 S 级单镜 `1 首帧 + 0–1 干声`）且按出场顺序编号？画面不露脸的角色是否被误提名字或误挂图？

### 第三步：输出唯一标准审查报告
```markdown
## 红线门禁审查报告｜[手册/单元ID]｜目标模型：Seedance [2.0/2.5]

- **最终裁决**：`PASS` / `FAIL（存在 N 项 P0 阻断项，严禁投入即梦生成）`
- **机械扫描（lint_prompt.py）**：P0=X｜P1=Y
- **独立语义复核**：P0=X｜P1=Y

### P0 阻断项（必须修改后复审）
1. **[单元ID｜红线编号]** 原文摘录：`...` → 违规原因：... → 最小修改指令（不改文风）：...

### P1 风险告警（建议优化，可由导演拍板放行）
1. **[单元ID｜红线编号]** 原文摘录：`...` → 风险提示：...

### 复审放行项（全部通过清单）
- [x] 模型语法与时间线合规
- [x] 三反原则与情绪物理分解
- [x] 参考图纯净度与光影交互
- [x] 空间拓扑、透视与接点咬合
```
