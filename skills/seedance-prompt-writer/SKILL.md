# Seedance 2.0 / 2.5 双版本视频提示词编译器（Station 3）

将 `director-storyboard` 的《导演分镜规格表》与 `visual-bible-art` 锁定的真实 `@资产名`，按用户指定的目标模型版本（**`2.0`** 或 **`2.5`**），编译为**高信噪比、可直接粘贴进即梦的纯净视频提示词**。

## 输入与输出契约

- **输入**：
  1. 当前幕《导演分镜规格表》（模型无关中间层）
  2. 当前幕已验收的 `@资产名` 清单（含 S 级首帧、中灰底单人图、纯净空景、`STYLE-REF`、主角干声 `@Audio` 与选配 `@Video`）
  3. 目标模型版本：**`Seedance 2.0`** 或 **`Seedance 2.5`**（若用户未声明，先确认或同时说明默认按哪一版编译）
- **输出**：写入分幕手册下半段的纯净提交块——每个单元包含：
  - **资产绑定卡**（明确上传顺序与每张图的精确控制职责，**不复制进即梦文本框**）
  - **纯净 Prompt 提交块**（0 导演台账泄漏，可直接复制并在即梦用 `@` 弹窗重绑）
  - 完成后**必须交由 `prompt-redline-auditor` 执行 Python Lint + 独立子 Agent 复核**，过审后才可交付即梦生产。

## 标准编译工作流（5 步）

### 第一步：选定模型适配器（严禁混写 2.0 与 2.5 语法）
- 编译目标为 **`Seedance 2.0`** → 必读 `references/profile-seedance-2.0.md`（镜号 `镜头1/2/3`、4–15s、单镜单一运镜、严禁精确时间戳、多人严禁三视图、推荐 3–5 素材）。
- 编译目标为 **`Seedance 2.5`** → 必读 `references/profile-seedance-2.5.md`（官方 4 段结构：素材绑定 → 一句话总纲 → 连续整数秒 `[0s-4s]` 时间线 → 一致性收尾；4–30s；超 4s 拍可复合运镜；支持多关键帧对齐、独立音频与参考视频、原生局部编辑与前后延长）。

### 第二步：执行「三反原则」与「情绪物理分解」
读取 `references/emotion-physics-lexicon.md`：
1. **情绪词清零**：彻底删除“彻底崩溃、满腹委屈、无比释怀、神情冷漠如水、微微一笑、极度震惊”等抽象情绪大词，全部翻译为**2–3 个摄像机可见的肌肉微动 + 呼吸停顿 + 视线落点 + 次动作**。
2. **反比喻**：删除“像…一样”“仿佛”“宛如”“如同”，只写可见的物理视觉事实。
3. **反重复写衣物**：造型已由 `@角色图` 或 S 级首帧锚定，正文不再重复罗列整套穿着，仅写衣物随动作/风发生的物理动态（如衣袖被扯紧、发丝被风吹动）。
4. **反瞳孔颜色描写**：禁止写虹膜/瞳孔颜色与夸张眼神光，统一写“视线落向某处”，避免触发模型瞳孔异常发光。

### 第三步：注入「光照-皮肤交互」与克制环境动态
读取 `references/lighting-surface-rules.md`：
- 为可见主角写清 **1–2 句物理光照落点**（主光源来自哪一侧、照亮哪半边脸、阴影落在眼窝/鼻翼哪侧、环境反光落在下颌/肩线），彻底消灭“角色像抠图贴进场景”的割裂感。
- 为每个镜头点缀 **2–3 个真实克制的环境动态**（发丝微动、空气尘粒/雾气、茶杯热气、窗外车灯掠过、衣料褶皱晃动），让画面“活起来”，但**坚决拒绝 5000–8000 字注水式过度堆砌**——官方证实高信噪比（单条 5–15s 约 `150–450` 中文字符，20–30s 约 `350–700` 中文字符）指令遵循最稳、最不易乱切漏演。

### 第四步：咬合出入点转场与镜尾呼吸留白
- 承接上一条的单元：第 0 秒直接写正在进行的动作与饱满情绪状态，封死 AI 0.5 秒静态冷启动。
- 场尾或情绪句尾单元：在最后明确写清 `0.8–1.2s` 的无台词静态/微动余韵（如闭唇沉默对视、微垂眼帘、肩头缓缓松落），供剪映做 L-Cut 或自然硬切。
- 声音设计：明确写实环境底噪 + 具体同步动作拟音；按官方规范**仅对字幕与配乐使用简短否定约束**（`无背景音乐，无字幕，无水印`），所有画面内容用正向视觉语言表达。

### 第五步：迭代修复纪律（迭代医生原则）
实测不满意时，严禁推倒重写全文：
- 对照 `docs/ERROR_PLAYBOOK.md`，**每次迭代只改 1–2 个变量**，完整保留已经成功的画面、运镜与光影描述；
- 若属于 `Seedance 2.5` 局部小瑕疵（如改一句台词、改一处表情、延长 3 秒），优先使用 **2.5 原生局部编辑 / 前后延长（输出 MOV 锁色温）**，而非整段重抽。

## 纪律红线

- 严禁把任何制片台账词（`MASTER-01`、`回环复用`、`后期贴轨`、`剪映镜像`、`压屏字幕`、`建议时长`）写进纯净提交块。
- 严禁在正文提及当前画面不露脸的角色名，也不得为其挂载参考图（防模型强行拉远景别或凭空画人）。
- 严禁强爆发戏绑定纯白 `#FFFFFF` 平静头肩特写；严禁多人镜绑定三视图母档。
- 交付给用户复制前，必须先跑通 `skills/prompt-redline-auditor/scripts/lint_prompt.py` 且获得 `PASS`。
