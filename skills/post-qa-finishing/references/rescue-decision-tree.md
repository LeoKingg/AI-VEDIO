# 4 级低成本修片决策树与两击止损协议

> **核心原则**：AI 抽卡最大的隐形成本是“为了改掉 5% 的小瑕疵，把 95% 完美的演技整条推倒重抽”。必须严格按 **`L1 → L2 → L3 → L4`** 成本由低到高逐级升级！

## L1｜后期 1 分钟零成本急救（成本 = 0 积分，首选）
- **越轴瞬移**（画内无文字/非左舵车）→ 剪映一键「水平镜像」；
- **边缘僵手 / 角落小穿帮 / 顶底略偏** → 放大 `105%–130%` + 微调 X/Y 构图裁出画外；
- **延长拼接微跳** → 按官方 SOP **前段尾裁 6 帧 + 后段头裁 1 帧**；
- **尾音截断咔哒声** → 结尾音轨加 **`0.15s` 音量包络淡出**；
- **单镜曝光/色温微偏（±10%内）** → 进调色做逐镜匹配，绝不重抽；
- **声音略细/略飘** → 调音高 `-0.5` 至 `-1` 半音 + EQ 轻推中低频，或画外音段直接独立贴轨。

## L2｜Seedance 2.5 原生局部编辑 / 延长 / 多机位重拍（保留 95% 成功画面）
- **适用**：表演与台词极佳，仅局部背景多出穿帮物件（如右后银色冰箱）、某 2 秒表情/动作略偏差、尾段少 2 秒呼吸余韵，或需把单机位完美表演重拍为多角度。
- **操作铁律**：
  1. 直接指代原片 `编辑 @视频1` / `向后延长 @视频1`（**绝不写“参考 @视频1”**）；
  2. 明确写清起止时间戳与 `从 A 改为 B`；
  3. 强制选择 **`MOV` 格式输出**最大限度锁定原有色温亮度；
  4. 多机位重拍或大改先跑 **`480p` 草稿测**，通过再出 `1080p`。

## L3｜Seedream 5.5 同图单轮局部微调首帧重跑
- **适用**：视频构图/站位/眼神根源出在首帧或母帧本身（例如首帧某人眼神看偏、多出空椅、桌角断头）。
- **操作铁律**：把已 70% 正确的首帧喂回 `Seedream 5.5`，**每轮只改 1 处 + 写全保留清单**，改完验收通过再重新驱动视频。

## L4｜迭代医生单变量改 Prompt 重抽（遵守《两击止损红线》）
- **单变量铁律**：绝不一口气推倒重写 5 个地方！只针对病灶改 1–2 个变量（如把抽象词换成物理后果链、把多音字换成同音字、把平静干声换成爆发档干声、把过长 15s 拆为 2 段）。
- **两击止损红线**：同一思路连抽 **2 次** 仍报同类错误，**立刻停止盲抽第 3 次**，强制切换工程维度：
  - 多人站位不对 → 外挂无字黑白构图草图；
  - 表演/运镜文字听不懂 → 切 `V-Ref` 挂载 5s 手机自拍/电影参考视频（或 3D 白模）；
  - 单段过载乱切 → 降维拆为 `M-Master` 或 `S-Struct`。
