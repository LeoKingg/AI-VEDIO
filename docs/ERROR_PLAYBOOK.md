# AI 视听制作实战错误复盘与避坑库（V3.0 全量生命周期版）

> **使用方式**：每条错误标注生命周期状态与适用模型边界，防止过时补丁污染新模型能力。  
> **状态标签**：
> - `CORE-PERMANENT`：底层影视/物理/多模态机制规律，跨模型永久生效；
> - `UPGRADED-IN-V3`：已在 V3.0 从顶层架构彻底根治（无需再靠零散补丁防错）；
> - `MODEL-BOUND`：与特定模型版本强相关（`2.0` / `2.5`），由对应编译器适配器分流处理。
