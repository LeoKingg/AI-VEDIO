# 1 → 100 电影感运镜调度与视觉语言库

> **目标**：把画面从“防穿帮的平庸固定机位”提升至“有呼吸、有权力关系、有纵深层次的院线摄影调度”。

## 一、六大高阶场面调度技法（超越“正反打站桩”）

| 技法 | 怎么做（可落地到 AI 分镜） | 适用情绪与戏剧功能 |
| :--- | :--- | :--- |
| **1. Z 轴纵深走位** | 不让两人一左一右横排站桩，改为一人前景微虚偏侧、另一人沿中后景纵深走向或背离镜头 | 用物理距离拉近/拉远外化权力压迫、试探逼近或决绝离开（特别适合 9:16 竖屏与 2.5 长镜） |
| **2. 焦点转移（Rack Focus）** | 前景清晰聚焦关键物证（空碗/合同/手机），台词落点瞬间平滑移焦至后景人物僵住的微表情 | 1 镜零剪辑完成“因果撞击”，比硬切高级 10 倍（`Seedance 2.5` 原生支持“焦点从前景平滑移至后景”） |
| **3. 框中框与前景偷窥遮挡** | 透过门框、玻璃缝、虚化餐杯或他人肩背局部遮挡拍摄主角 | 制造“隐身目击者”的真实纪实偷窥感，并视觉化“被家庭/现实困住”的窒息感 |
| **4. 焦段阶梯压迫** | 同一空间随冲突升温逐步收紧焦段：`28mm` 广角立秩序 → `50mm` 中景对峙 → `85mm` 长焦压扁背景剥离毛孔 | 参考《十二怒汉》，无需人物大喊大叫，观众生理自然感到喘不过气 |
| **5. 微荷兰角（5°–8°）+ 极缓推** | 静态母帧先烘焙 5° 倾斜构图，进视频配合持续缓推压窄呼吸空间 | 表现理亏、世界观崩塌或心理防线瓦解（现实主义严禁超过 10° 避免廉价眩晕） |
| **6. 30°–60° 低角弧线绕推** | 自略低于眼平的中近景流畅起推，围绕主角滑出 30°–60° 弧线边推边升至眼平大特写 | 全幕唯一情绪核爆点的“标点符号式运镜”，完成弱者反攻的尊严升格 |

## 二、运镜节制与模型稳定性纪律
- **单切镜单一主运动**：同一个镜头切段内严禁同时叠写“左摇 + 环绕 + 急推”（模型无法仲裁必抖屏）；`Seedance 2.5` 超过 4s 的单拍最多做 1 次方向平滑的复合过渡（如缓推顺转微仰）。
- **高难运镜直接交 `V-Ref`**：希区柯克变焦、360° 环绕、复杂手持穿框跟拍等文字难写准缓动曲线的运镜，直接挂载 3–5s 实拍/电影参考视频（`@视频1 仅参考运镜轨迹与缓动速度`）。
- **动静配比红线**：全幕 `40%–55%` 克制固定/微推打底，用静止衬托关键转折处的 `1–2` 次标志性运镜爆发。
