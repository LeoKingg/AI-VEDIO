# 平台分发与安全区预设：抖音 16:9 横屏电影黑边封装（`platform_douyin_letterbox`）

> **适用范围**：主打电影质感、高完播率与 IP 心智沉淀的抖音/视频号 1.5–3 分钟情感剧情中视频（双母版输出：16:9 原生横屏母版 + 9:16 上下纯黑边竖屏分发版）。

## 1. 画幅与导出规格
- **生成母版**：全链路 `16:9`（`1920×1080` 或超分 `2K/4K`），`24fps`（全片统一电影帧率，可选 `30fps`），高码率 H.264/H.265。
- **抖音竖屏封装画布**：`9:16`（`1080×1920`），将 `16:9` 主画面（`1080×608`）居中偏上 `2%–3%` 嵌入，上下留纯黑电影边。

## 2. 视觉与 UI 安全区硬规范（Station 2 摄影必检）
```text
┌───────────────────────────┐  9:16 竖屏画布 (1080×1920)
│   [顶部平台栏避让 12%]     │  避开搜索/关注/状态栏
│   主标题（≤12字强冲突钩子） │  上黑边黄金区
│   副标签（真实事件/系列号） │
├───────────────────────────┤
│  [16:9 主画幅安全区规范]   │  · 主角双眼/核心道具落在中心 80% 宽 × 80% 高内
│    16:9 电影感主画面       │  · 画面右缘 12% 不放关键小字或决定性微表情（防横屏播放器/右侧栏压迫）
│                           │  · 画面底缘 10% 留白不裁断手部/核心碗具（兼顾 16:9 原生版底部字幕）
├───────────────────────────┤
│   单行/双行电影字幕居中    │  下黑边上半区（右边界缩进 18% 避开点赞/评论/收藏竖栏）
│   [底部账号/文案栏避让 18%]│  严禁把字幕压入底部文案区
└───────────────────────────┘
```

## 3. 爆款完播硬指标
- **0–3 秒**：画面即冲突 + 0–1.5s 强情绪人声或动作硬音效 + 上黑边钩子标题互补不复读；
- **全片响度**：对白清晰落于 `-14 LUFS`（峰值 `-6dB` 至 `-12dB`），BGM 严格压低让位人声；
- **防误出原生字幕**：所有生视频 Prompt 末尾必带 `无背景音乐，无字幕，无水印`，字幕统一在后期精确校对口播后压制。
