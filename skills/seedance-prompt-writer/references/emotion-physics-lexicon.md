# 中国当代现实主义：情绪→物理微动翻译词典

> **底层原因**：`Seedance 2.0/2.5` 看到“彻底崩溃、悲伤欲绝、无比释怀、微微一笑”等抽象大词时，会字面过度执行（变成舞台剧浮夸扭曲、假笑，甚至在 2.5 触发瞳孔异常反光）。改为**2–3 个可见肌肉动作 + 呼吸停顿 + 视线落点 + 次动作**，真人感立刻质变。

## 一、核心禁用大词 → 现实主义物理微动对照表

| **满腹委屈 / 悲伤难过 / 心酸** | 眼睑微垂，嘴角极轻地向下收紧，喉结/颈部轻咽一口，视线从对方脸上移开落向桌面，手指无意识攥紧衣角/杯沿 |
| **心灰意冷 / 彻底死心 / 神情冷漠如水** | 原本舒展的嘴角一寸寸平复静止，眼底光亮暗下，闭唇沉默停顿两秒，缓缓低眸又平视前方，肩膀微微松沉 |

## 二、让角色“像真人活着”的 3 条微表演纪律

1. **绝不站桩念词（配 1 个自然次动作）**：说话或听话时，明确手和重心的物理归宿（例如：手指摩挲杯沿、捏紧旅行包带、搭在椅背、指尖轻敲手机背面、自然眨眼与胸口呼吸起伏）。
2. **动作后紧接下一个动作，不留死空白**：写完“嘴角极轻抬起两毫米”后，紧跟下一个可见动作（如“随即垂眼看向账本”），不给模型留出莫名尬笑或发呆的空白窗口。
3. **重锤前留半拍呼吸气口**：关键一句台词之前，写清“闭唇静听约两秒 / 深吸半口气后开口”，既给表演留出真实人类反应时间，又让声音更有爆发对比。
