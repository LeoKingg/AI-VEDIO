# 电影摄影思考前置层（Photographer's Notes）

> 生图 Prompt 不是“罗列画面物体的清单（Object List）”，而是**摄影指导写给片场的工作笔记**——约束的是模型取舍画面、光线与瞬间的视觉决策。

## 一、四条核心摄影哲学

1. **拍 Moment，不拍 Object（瞬间大于状态）**
   - 差（状态）：“一位 55 岁女性站在走廊里看着女儿。”
   - 优（瞬间）：“她刚被扯住左臂骤然停步，肩线绷紧半转未转，手指还停在防盗门把上方几厘米处。”
2. **Anticipation is stronger than Action（蓄势大于做满）**
   - 最有电影张力的一帧不是嚎啕大哭张大嘴，而是**眼眶通红刚噙住泪、下唇微微抿紧、爆发前最后半秒的死寂**。这也天然避免 S 级首帧喂给视频后出现极端表情僵死（呼应 `ERR-011`）。
3. **克制即电影感（决定“什么不拍”）**
   - 真正的高级感来自做减法：把不需要交代的墙角、天花板、远景沉进暗部或留出 **30%–50% 负空间**，颜色来自真实光源与空气，而不是往屋里塞满五颜六色的家具。
4. **Discover, not Present（偶然目击感，而非怼脸摆拍）**
   - 善用门框、桌角、杯盏、车窗边框做前景半虚化遮挡，让镜头像一个隐身在房间角落的冷静目击者。

## 二、每张 S 级首帧动笔前三问

1. **这一幕真正拍的是什么情绪？**（决定光影配方卡，而非堆砌形容词）
2. **画面定格在“刚刚发生什么 / 下一秒要发生什么”？**（决定人物微姿态与重心）
3. **本帧主动克制掉什么元素？**（决定负空间留白区域与背景虚化/压暗比例）

## 三、Attention 注意力指向表（杜绝影楼写真感）

| 人物视线落点 | 传递的叙事与心理 |
| :--- | :--- |
| 看向另一位角色（略偏轴） | 关系交锋、对峙、隐忍试探 |
| 看向手中物件（账本/手机/钥匙/卡片） | 回忆、算计、现实重压、决断 |
| 垂眼看桌面或地面 | 疲惫、委屈、羞愧、无力回避 |
| 望向窗外或远方画外空间 | 渴望逃离、等待、疏离释怀 |
| 闭眼微仰或低头 | 承受、深呼吸强忍、情绪沉淀 |
| **直视摄影机镜头** | **默认严禁——立刻变影楼写真/网红自拍** |

## 四、Visual Hook 三眼视线路径（适合 S 级首帧构图）

设计 S 级剧照首帧（尤其是抖音前 3 秒开场首帧）时，让观众目光自然按 3 步流动：
1. **第一眼（最亮处或最强对比点）**：落在核心叙事焦点上（如暖黄吊灯照亮的半张泪眼侧脸、暗调桌面上被推回的旧账本、车窗外透进的金色日照金山）。
2. **第二眼（人物微姿态与关系）**：扫到人物绷紧的手指、微沉的肩膀或对峙另一方的虚化肩背。
3. **第三眼（环境与暗部留白）**：读懂陈旧老式家居、逼仄走廊或辽阔高原的处境，情绪在脑中自然闭合。
