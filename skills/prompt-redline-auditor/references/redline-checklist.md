# 提示词红线分级门禁清单（P0 阻断 / P1 告警）

> 审查原则：**只对照本清单与 `docs/ERROR_PLAYBOOK.md` 逐项打勾 `PASS / FAIL`，绝不凭主观喜好润色或重写文风。**

## 一、P0 阻断级红线（检出任意 1 项即 `FAIL`，必须修正后再审）

| 编号 | 关联错误库 | 检查项 | 判定标准 |
| :--- | :--- | :--- | :--- |
| **`RL-01`** | 模型语法 | **2.0 / 2.5 语法隔离** | `2.0` 出现精确时间戳（`0s-3s`/`0-3秒`）或单镜叠写多个冲突运镜 → `FAIL`；`2.5` 时间戳不从 `0s` 起、存在断档/重叠或总长 > `30s` → `FAIL` |
| **`RL-02`** | `ERR-013` | **抽象情绪大词清零** | 纯净提交块内出现“彻底崩溃、满腹委屈、无比释怀、神情冷漠如水、歇斯底里、悲痛欲绝、微微一笑”等未物理分解的抽象情绪大词 → `FAIL` |
| **`RL-03`** | 视觉污染 | **比喻与瞳孔色禁令** | 正文出现“像…一样、仿佛、宛如、如同”或描写虹膜/瞳孔颜色、自发光眼神词 → `FAIL` |
| **`RL-04`** | 制片剥离 | **台账词零泄漏** | 纯净提交块内出现 `MASTER-`、`SEG`、`EDIT`、`回环复用`、`后期贴轨`、`剪映镜像`、`压屏字幕`、`建议时长` 等制片备注词 → `FAIL` |
| **`RL-05`** | 官方规范 | **`@资产名` 绑定闭环** | 正文出现未在绑定卡声明的 `@资产名`，或挂了画面不露脸的角色图/在正文提及未出场角色名 → `FAIL` |
| **`RL-06`** | `ERR-002`/`007` | **高危参考图禁挂** | 强爆发/暗调戏绑定纯白 `#FFFFFF` 平静头肩特写，或多人场景绑定三视图母档（`三视图`） → `FAIL` |
| **`RL-08`** | `ERR-001` | **跨空间与 180° 反转禁令** | 单条视频内强行跨越两个完全不同物理空间，或要求 180° 视角大反转 → `FAIL` |
| **`RL-09`** | `ERR-012` | **车内透视与刚体隔离** | 车内视角混挂车外参考图，或用正前视车厢图要求 90° 转向拍侧门且无同角度 S 级首帧 → `FAIL` |
| **`RL-10`** | `ERR-011` | **禁喂极端动态截帧** | 将双手悬空/张嘴/转身一半的动态截帧喂给同机位续拍视频 → `FAIL` |
| **`RL-16`** | `ERR-016` | **核心连戏道具断链禁令** | 凡跨 ≥ 2 个镜头且近景可见的关键剧情道具，若相关生图首帧或视频单元未共同溯源到同一 `PROP` 锚图或上游首帧/静帧 → `FAIL` |
| **`RL-17`** | `ERR-016`/`017` | **参考图与状态/结构冲突禁令** | 绑定空景/参考图的既有物体状态或空间结构（如 `S0` 桌上有鱼、墙无门洞）与正文要求相反（如 `S1` 桌中留空、露出门洞）且未提供对应 `S1` 状态首帧，或后场正脸重戏角色首现时无前置资产锚 → `FAIL` |
| **`RL-18`** | `ERR-015` | **同源环境重复挂载与空景脱节禁令** | 已绑定空景/首帧/定妆帧却仍重复挂载同源 `STYLE-REF` 风格锚（机械扫描直接阻断）；或 A 级绑定空景却未交代人物在空景中的位置、朝向与机位方向 → `FAIL` |
| **`RL-19`** | `ERR-018` | **变更全局影响遍历同步（防顾头不顾尾）** | 资产或 Prompt 发生局部改动后，若未同步遍历更新《视觉圣经》、可视化分镜、本镜生图/视频 Prompt、下游派生首帧（含 `S0→S1`）、相邻衔接镜及实测台账，导致任意两处口径矛盾 → `FAIL` |

## 二、P1 风险告警项（逐条提示导演决策，不强制阻断）

| 编号 | 关联错误库 | 检查项 | 告警触发条件 |
| :--- | :--- | :--- | :--- |
| **`RL-07`** | 信噪比控制 | **负面词泛滥与注水篇幅** | 视觉否定词堆砌超过 8 条，或单条视频正文超过高信噪比阈值（2.0 > 550 字；2.5 > 950 字）或过薄（< 60 字） |
| **`RL-11`** | 电影感底座 | **光照-皮肤交互缺失** | 含人物近景/中景的视频正文未交代主光源方向及光线落在面部/身体何处 |
| **`RL-12`** | `ERR-008` | **空间拓扑与冷启动隐患** | 承接上一条的镜头第 0 秒写了“静静站立/原地站着”等冷启动词；或全景相距较远却在特写强加前景肩 |
| **`RL-13`** | `ERR-014` | **镜尾呼吸余量缺失** | 情绪句尾或场次收尾镜头未预留 `0.8–1.2s` 无台词沉默/微动余韵 |
| **`RL-14`** | 导演美学 | **无动机炫技运镜** | 连续 3 个以上镜头每镜强行切换不同大动作运镜（环绕/急推/甩镜）且无明显情绪升级理由 |
| **`RL-15`** | 2.5 长片锚定 | **长时长防漂移复述缺失** | `Seedance 2.5` 单条超过 15 秒的多拍提示词，后半段未极简复述主角核心外观锚点 |
