# 多模态视频 Prompt 编译器（Station 5｜Agent 5｜Seedance 2.5 主力）

遵循 BytePlus 2026-11 官方指南与“**任务分配（Job Assignment）而非散文堆砌**”哲学——**文字管语义（谁干什么 + 物理后果 + 声景），参考管标准（外貌/实景光色/运镜缓动/音色节奏）**——将站 1–4 产出精准编译为可直接粘贴进即梦的高信噪比纯净视频 Prompt。

## 强制输入契约

1. 站 1《导演分镜规格表》（含 5 模生成路由）+ 站 2《2D 摄影调度表》（零钟面词）。
2. 站 3 已验收资产清单与 `manifest.json`（含 `S0/S1` 状态、`removed_objects` 粉红大象黑名单）。
3. 站 4《表演与声学导演卡》（潜台词转折、物理后果链、情绪档干声、V-Ref 参考建议）。
4. 目标模型版本：**默认 `Seedance 2.5`**（若项目 `manifest.json` 指定 `2.0` 则切 `2.0` 适配器，**同场严禁混用 2.5 与 2.0 独立生成**）。

## 标准编译工作流（5 步）

### 第一步：加载模型适配器 + 写前 5 项硬拦截（缺锚停笔）
- 目标为 **`Seedance 2.5`（默认主力）** → 必读 `references/profile-seedance-2.5.md` 与 `references/multi-shot-and-reshoot.md`（区分 `2.5` 旗舰 `1080p/4K 10-bit + Draft 样片直升` 与 `2.5 Flash` `限 720p 无 Draft`）。
- 目标为 **`Seedance 2.0`（兼容降级）** → 必读 `references/profile-seedance-2.0.md`。
- **写前 5 项硬拦截**（任意一项未过，立刻退回对应上游，严禁靠文字硬拗）：
  1. **零外来风格图**：绑定卡与正文**绝不允许出现 `STYLE-REF` / `@风格光影锚`**；
  2. **Locked vs Unlocked 模式对齐**：只有单图/首尾帧走 `first_frame` 才是像素锁定首帧；进入多素材全能参考（R2V）属于 Unlocked，严禁默认其 100% 锁画幅与首帧像素（需强锁首帧的单人特写优先精简参考数或配合 `Draft Mode` 验首帧；且参考图分辨率尽量不高于输出分辨率防指纹伪影）；
  3. **视觉依据闭合与无脸 Route C 隔离**：露脸主体必在首帧/母帧或角色图中锁死；背影/斜侧背关键帧急转头露正脸必保角色正脸锚（槽位紧张时宁可将次要镜干声改后期贴轨）；多角色多切段仅部分人物挂卡时，须显式写清未挂卡角色外观唯一来源；**画外不露脸角色、前景虚化肩背与纯手顶拍绝不挂其角色图；走 `Route C` 后期贴轨的无脸镜头视频端严禁挂 `@干声` 与写 `{台词}`**（注：2.5 原生支持 `嘴唇闭合 + V.O.`，但 Route C 后期贴轨时剥离人声更干净）；
  4. **状态一致与零粉红大象**：`S1` 镜仅引用 `S1` 资产，正文**严禁出现 `manifest.json` 的 `removed_objects` 禁词**，菜盘/陈设直接“沿用首帧原有摆位”不重绘；
  5. **零钟面词与零冗余界面参数**：全文仅使用站 2 的 2D 画面空间语言，**不在正文堆砌 `16:9横屏`/分辨率等平台参数**。

### 第二步：按「首出场顺序 + 关键帧连续序」排布参考素材与显式主体定义
1. **首出场排序 & 关键帧严禁跳号**：单镜首帧排第 1 顺位；**多关键帧（`SEQ-Grid`）必须把全部关键帧连续排在最前顺位（`1..N`）**，辅助角色卡与干声紧随其后，严禁在关键帧之间插入角色设定卡打断 `图片1至图片N` 连续编号！
2. **显式主体唯一标签（极简不啰嗦）**：开篇用 1–2 句紧凑定义角色标签与职责（避免占去 30–40% 字数，绝不在不同段落重复粘贴同一句声明），全文始终使用同一称呼。
3. **音频「位置效应」与 `V-Ref` 去音轨**：关键 `@干声` 尽量只配在**近景/特写 + 低动作**镜头（中远景强动作易触发原声重合成变声），每句台词留 ~1s 气口；`V-Ref` 参考视频务必先剥离音轨（`ffmpeg -an`）；音、视频参考总长各自 `≤30s`。
4. **锚点成片反哺与 `return_last_frame`**：首个过审锚点可作影调参考；连续顺接镜优先使用 `return_last_frame` 真实成片尾帧作下一镜首帧。

### 第三步：按 5 模路由编译高信噪比时间线（`2.5` 整数秒 + 结局状态 / `2.0` 镜号制）
读取 `references/multi-shot-and-reshoot.md`：
- **`SEQ-Multi`（多镜头连拍主力）**：
  - `2.5` 使用无断档连续**整数秒** `[0s-4s]`、`[4s-9s]`（单段 ≤30s，**正文严禁使用 `0.5s`/`0.8s`/`1.2s` 小数秒卡帧**；超过 15s 时在后半段用 5–8 字复述主角外观锚）；**每段结尾加 1 句「可观察物理结局状态（Observable End State）」**（纯肉眼可见终态，如“结束时瓷盘落于果盘左侧，双手撤离”）；
  - `2.0` 使用 `镜头1：`、`镜头2：`（总长 8–15s，严禁出现任何时间戳）。
- **`SEQ-Grid`（线稿分镜 / 多关键帧）**：
  - 多关键帧严格连续对齐：首句写 `按顺序将 @图1 至 @图N 作为关键帧`（官方注：多宫格线稿仅作走位参考不像素对齐，像素级对齐必须用独立多关键帧）；
- **`M-Master` / `S-Struct`**：首句极简声明 `@首帧/母帧 为开场起点`，从第 0 拍闭唇蓄势态起势，**不重复冗长描写首帧里已锁定的静态墙面、桌面摆设与整套衣着**（防止文图冲突与稀释动作权重）。
- **`V-Ref`**：显式声明无音轨 `@视频1` 仅迁移动作/微表演或运镜轨迹。
- **`E-Edit`（原生画面/音频编辑 / 延长 / 2.5 多机位重拍 / 无缝转场）**：直接指代 `@视频1`（**严禁写“参考 `@视频1`”**），编辑主体替换必写「时间线继承」，外部非 2.5 视频编辑先裁成 `8n+1` 帧防 0.3s 时差，强推 `MOV`（`yuv444p` + PCM）；支持纯音频编辑（改句/去 BGM）与双视频无缝转场补帧。

### 第四步：注入物理后果链、逐段单音效与 2.5 官方声学规则
1. **情绪物理化 + 单切片动作减负 + 正向神态**：每 `4–5s` 切片聚焦 `1–2` 个主动作+物理后果链，**用正向神态替代高频画面否定词**（如写“神情冷淡、嘴角平直低垂”“视线稳锁画外右侧”，不要单条里连写 3 遍“毫无笑意”或 2 遍“绝不看向镜头”）；防发光眼写 `眼神自然正常，无任何眼部发光`。
2. **光照-皮肤交互**：每个含人镜头带 1 句具体实用光源落点与阴影过渡。
3. **官方 4 类定界符与防杂音/防字幕/强禁 BGM**：
   - 台词 `{台词}`（配声线形容词双重强化与同音字纠音；需逐句差异化情绪且严防字幕时采用官方格式 **`角色台词（情绪）：“内容”`**，避免在台词后复述词语并追写语气微动）；
   - **单 `<音效>` 逐段内嵌**：**每个 `<>` 只写 1 个独立音效并紧贴对应动作的时间戳切片**，绝不把跨切镜的 4–5 个音效全打包进文末一个 `<>`；删除非必要的液体/水/波浪/回声词防 2.5 音频咕噜杂音；
   - **首尾双写强禁 BGM（2.5 官方 FAQ）**：不要只写单薄一句 `无背景音乐`，且删掉收益极低的泛化套话（如 `画面流畅无闪烁，五官与光影前后一致`）；改在**开篇或结尾显式枚举** `全程无背景音乐、无配乐、无BGM、无器乐旋律，无字幕，无水印`（高危乐段首尾各声明一次）。
4. **严格对齐官方高信噪比篇幅**：**`2.5` 常规单镜与 2–3 切多镜一律控制在官方建议 `≤500` 汉字**（15–30s 复杂长多镜可放宽至 `500–700` 字，绝不写 800 字废话）；`2.0` 单镜 `150–350` 字、多镜 `300–500` 字。

### 第五步：写入标准提交块并移交站 6 门禁
所有视频单元写入 `03_actXX_handbook.md` 第四章，带标准 `<!-- PROMPT_START: ID -->` 标记，**必须经站 6 `redline-auditor` 机械+语义双审 `PASS` 后**，方可在仓库根目录运行 `python3 scripts/build_workbench.py` 编译工作台交付。

## 权责边界与冲突升级

- **严禁越权**：不私自修改剧情转折与台词核心原意（归站 1），不擅自更改 2D 朝向与安全区（归站 2），不绕过站 6 红线审计直接交付用户。
- **冲突升级**：若站 4 表演细则与单段高信噪比字数上限冲突，立即上报总调度裁剪次要细节保留核心物理后果链。
