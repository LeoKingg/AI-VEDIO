# V3.0 红线分级门禁总表（`RL-01` ~ `RL-30`｜机械扫描 + 语义盲审）

> 标注 `[AUTO]` 的规则由 `scripts/lint_prompt.py` 零幻觉毫秒拦截；标注 `[SEMANTIC]` 的规则由独立隔离审查子 Agent 复核。

## 一、P0 阻断级红线（任意 1 项命中即 `FAIL`，严禁进即梦）

| 编号 | 检测方式 | 适用对象 | 判定标准 |
| :--- | :---: | :---: | :--- |
| **`RL-01`** | `[AUTO]` | 视频 | `2.0` 出现精确时间戳 → `FAIL`；`2.5` 非编辑/延长任务若含多镜头却缺时间戳（误用 2.0 镜号制），或时间戳不从 `0s` 起、存在断档/重叠、超 `30s` 上限 → `FAIL` |
| **`RL-02`** | `[AUTO]` | 视频 | 出现禁用抽象情绪大词（彻底崩溃/歇斯底里/微微一笑/极度震惊/狂热等易致浮夸或 2.5 发光眼词）→ `FAIL` |
| **`RL-03`** | `[AUTO]` | 生图+视频 | 出现比喻词（仿佛/宛如/犹如/像…一样）或瞳孔/虹膜色与发光眼触发词 → `FAIL` |
| **`RL-04`** | `[AUTO]` | 生图+视频 | 制片/导演台账词（`MASTER-`、`SEG`、`EDIT`、`S0`、`S1`、参考图1、回环复用、后期贴轨、建议时长等）泄漏进纯净提交块 → `FAIL` |
| **`RL-05`** | `[AUTO+SEM]` | 生图+视频 | 正文引用了未在绑定卡声明的 `@资产名`；视频违规挂载画外不露脸角色图/前景虚化肩背全身图；**背影/斜侧背关键帧转头露正脸时未挂 `CHAR-SHEET`（或未注明无卡角色仅由对应关键帧锁定）** → `FAIL` |
| **`RL-06`** | `[AUTO]` | 视频 | 视频声明头或正文引用老式全身`三视图`/`CHAR-BASE`/`母档`（`2.0` P0；`2.5` 多人高危），或检出 `#FFFFFF`/纯白底/表情网格 → `FAIL`（V3.1 一卡双区 `CHAR-SHEET`/`设定卡` 配合 `SHOT-MASTER` 放行） |
| **`RL-08`** | `[SEMANTIC]` | 视频 | 单条视频内无过渡跨不同物理空间，或强行要求 180° 视角反转（`ERR-001`）→ `FAIL` |
| **`RL-09`** | `[SEMANTIC]` | 生图+视频 | 车内视角混挂车外图，或用正前视图强转 90° 拍侧门无同角首帧（`ERR-012`）→ `FAIL` |
| **`RL-10`** | `[SEMANTIC]` | 生图+视频 | 喂极端动态帧（大张嘴/双手悬空）作同机位起手，或 `SHOT-MASTER` 未锁定第 0 拍闭唇放松态（`ERR-011`）→ `FAIL` |
| **`RL-16`** | `[SEMANTIC]` | 生图+视频 | 跨 ≥2 镜近景核心道具未共同溯源至 `manifest.json` 注册的同一 `PROP` 锚图 → `FAIL` |
| **`RL-17`** | `[AUTO+SEM]` | 生图+视频 | 单元状态为 `S1` 却绑定了 `S0` 旧空景/资产，或后场主角首现前未前置定型 → `FAIL` |
| **`RL-18`** | `[AUTO]` | 视频 | **任何视频单元绑定或引用外来 `STYLE-REF` / `@风格光影锚`**（`ERR-021` 零容忍）→ `FAIL` |
| **`RL-19`** | `[AUTO+SEM]` | 跨文件 | 手册引用的 `@资产名` 未在 `manifest.json` / `02_asset_registry.md` 注册，或局部改动未同步遍历受影响下游 → `FAIL` |
| **`RL-20`** | `[SEMANTIC]` | 空景+首帧 | `S0→S1` 物体移位只写原位消失（`Origin -`）却遗漏同房间新落点补放（`Destination +`）→ `FAIL` |
| **`RL-21`** | `[AUTO]` | Seedream生图 | 首帧/母帧（`SHOT-START`/`SHOT-MASTER`/`KEYFRAME`）**超 `280` 字**，或视觉否定词（除无字无水印外）`>1` 处，或含静态图运镜词（推镜/跟拍/环绕）与画质吹水词（`8K`/`masterpiece`），或含人首帧空景排第 1 顺位 → `FAIL` |
| **`RL-22`** | `[SEMANTIC]` | 生图+视频 | 机位高度遮挡核心道具、左右负空间数学矛盾、模糊断桌词致近端截断、可见在场座位出现空椅穿帮（`ERR-025`）、**或同侧桌缘新增道具与入画手臂未交代上下/旁侧越过**（`ERR-031`）→ `FAIL` |
| **`RL-23`** | `[SEMANTIC]` | 生图+视频 | 图文人数对抗（画 5 人只绑 1 图、喂带头图下令切头）、模糊手数词（“几双手”）或解剖指向矛盾 → `FAIL` |
| **`RL-26`** | `[AUTO]` | 生图+视频 | **任何发给模型的 Prompt 正文泄漏 360° 钟面方位词**（`6点`/`8点半`/`9点`/`10点`/`12点`/`8:30` 等，`ERR-022`）→ `FAIL` |
| **`RL-27`** | `[AUTO]` | 生图+视频 | **粉红大象触发词泄漏**：剔除注册资产标签后，正文出现 `manifest.json` 登记的 `removed_objects` 禁词（如 `旧铁壶` 等已移除物件名，`ERR-023`）→ `FAIL` |
| **`RL-29`** | `[SEMANTIC]` | 跨幕交接 | 第 `N≥2` 幕未填写 Cross-Act 4 维交接卡，或与第 `N-1` 幕末镜妆容泪痕/情绪转折/站坐姿态断层（`ERR-026`）→ `FAIL` |
| **`RL-31`** | `[AUTO]` | 视频 | **无脸镜头音画同禁（`ERR-033`）**：俯拍桌面/手部特写等无脸镜头在视频 Prompt 内违规绑定 `@干声` 或写入 `{台词}`，易诱发拉远或虚构口型 → `FAIL` |

## 二、P1 风险与 1→100 质量告警项（逐条提示总调度/导演决策）

| 编号 | 检测方式 | 适用对象 | 触发条件 |
| :--- | :---: | :---: | :--- |
| **`RL-07`** | `[AUTO]` | 生图+视频 | 生图首帧/母帧在 `261–280` 字预警区；视频 `2.0 > 650` 字或 `2.5 > 950` 字，或正文 `< 60` 字过薄；视频视觉否定词 `> 6` 处 |
| **`RL-11`** | `[AUTO]` | 视频 | 含人物视频正文缺失明确物理光源/光影落点（精准词库，已修复“电影/目光”误绕过 Bug） |
| **`RL-12`** | `[SEMANTIC]` | 视频 | 承接镜第 0 秒冷启动，或相邻同角色两镜未拉开景别/构图导致跳剪风险 |
| **`RL-13`** | `[SEMANTIC]` | 视频 | 情绪句尾或场尾未预留 `0.8–1.2s` 无台词微动呼吸余韵 |
| **`RL-14`** | `[SEMANTIC]` | 视频 | 单切镜叠写多个冲突运镜、未写动作→物理后果链，**或单 `4–5s` 切片堆叠 `>3` 个独立微动作致 2.5 吞动作**（`ERR-032`） |
| **`RL-15`** | `[AUTO+SEM]` | `2.5` 视频 | `Seedance 2.5` 时长 `>15s` 的多拍单元后半段未极简复述主角外观锚点；或编辑/延长误写“参考 `@视频1`” |
| **`RL-24`** | `[SEMANTIC]` | 视频 | 同场混用 Seedance 2.0 与 2.5 独立生成引发色偏，或连续多次延长未做画质保真（`ERR-028`） |
| **`RL-25`** | `[SEMANTIC]` | 生图+视频 | 老年/高频对白近景角色缺失桌面手部微动作或使用正面大平光，易出现数字人播报感 |
| **`RL-28`** | `[AUTO]` | 视频 | `{台词}` 密度过高（按正常语速 `>4.8 字/秒` 或无留白余量），易致抢拍、吞字或口型漂移 |
| **`RL-30`** | `[SEMANTIC]` | 全链路 | 关键眼神/道具落入平台 UI 或字幕避让雷区（`presets/platform_*.md`），或爆发戏误挂平淡干声档 |
| **`RL-32`** | `[AUTO+SEM]` | 生图+视频 | **`35/50mm` 空间首帧与连续运动视频将 `@SCENE` 弱化为“木纹/光比”色卡而未明写继承同房间空间布局与 `S1` 迁移动态**；或 `CHAR-SHEET` 含“双区”且缺左右占比与鞋底留白锁（`ERR-031`） |
