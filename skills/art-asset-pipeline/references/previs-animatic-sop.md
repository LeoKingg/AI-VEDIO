# 零视频积分 Pre-Vis 动态分镜预演规范（Animatic SOP）

> **为什么高手一定要做 Pre-Vis**：视频抽卡最贵的成本不是几块钱积分，而是“全部视频抽完进剪映一拼，才发现前 3 秒太慢、某句台词 4 秒根本念不完、或者两个相邻镜头视线打架”。用静态图先拉一版动态预演，**花费 5 分钟、0 视频积分，就能提前消灭 80% 的节奏与连戏返工**。

## 4 步极简动态预演流程（5–10 分钟完成一幕）

1. **素材入轨**：把站 3 验收通过的本幕静帧（`SHOT-START` / `SHOT-MASTER` / 黑白分镜草图）按剧情顺序拖入剪映时间线。
2. **铺粗音轨（Scratch Audio）**：
   - 用手机自己按真实情绪语速把整幕台词快速录一遍（或用剪映免费 TTS 粗配），加上 `1–2` 处核心音效占位（如拍桌声、摔门声）。
   - 根据人声真实自然语速**反推并校准每个切镜的精确时长**（若发现某镜预计 4s 但真人急着念都要 5.5s，立刻在进视频生成前把该镜改为 6s 或砍精台词！）。
3. **4 项预演验收门禁（全部过关才允许进即梦烧视频积分）**：
   - [ ] **0–3 秒抓人度**：从 `00:00` 播到 `00:04`，画面切换与第一声强钩子是否瞬间抓住注意力？
   - [ ] **视线与轴线连贯**：连续播放相邻正反打静帧，角色 A 朝左、角色 B 朝右的视线是否自然对撞、绝不跳轴？
   - [ ] **相邻景别防跳剪**：同一角色连续出镜时，景别/构图变化是否清晰自然、无同构图生硬跳帧？
   - [ ] **安全区无遮挡**：在剪映叠加半透明抖音 UI/字幕参考框，确认所有关键眼神与桌面证物均无遮挡。
4. **回写校准秒数**：将预演测出的真实秒数更新回站 1 分镜表与站 5 编译器时间线（尤其对 **Seedance 2.5 整数秒时间戳 `[0s-4s][4s-9s]`** 极具决定性价值！）。
