# 模型适配器：Seedance 2.5 主力引擎规范（BytePlus 2026-11 官方对齐）

> **V3.0 默认主力引擎**。严禁与 Seedance 2.0 混用在同一场戏内独立生成（两代存在明显审美色偏；若必须承接 2.0 成片，须走 2.5 视频延长并输出 `MOV`）。

## 一、Seedance 2.5 核心能力与官方参数边界

| 能力维度 | Seedance 2.5 标准版 | Seedance 2.5 Flash | 实操建议甜区 |
| :--- | :--- | :--- | :--- |
| **单次时长** | `4–30 秒` | `4–30 秒` | 常规多镜头连拍 `10–25s`（主力甜区 `10–20s`）；一镜到底/重拍 `15–30s` |
| **素材硬上限** | `30 图 / 10 视频 / 10 音频` | `10 图 / 5 视频 / 5 音频` | **图像主体 `1–5`（上限建议 `≤8`），音视频主体 `1–5`（单段 `5–10s`）** |
| **时间控制** | 原生支持**连续整数秒时间戳**（`[0s-4s][4s-9s]`） | 同左 | 严禁时间断档/重叠；单拍 `3–8s` 最佳；不写“每秒摇头3次”高频微时序 |
| **多视图角色** | `1–5` 主体时支持多视图 | 同左 | `>5` 主体须拆单视角单图；最稳组合仍为 `CHAR-FACE 70% + CHAR-VID` |
| **任务锁类（Locked）** | 编辑 / 首尾帧 / 延长自动锁定比例（编辑同锁时长） | 同左 | 编辑与延长强推输出 **`MOV`** 格式，保色温/亮度/音画无损衔接 |
| **非锁类（Unlocked）** | 全能参考 / 多格线稿分镜（`≤15` 格）/ 多关键帧 | 同左 | 概念走向用无字线稿分镜；像素级精准构图用按序独立多关键帧 |
| **省预算工作流** | 支持 **`480p` 草稿试拍 → `1080p/4K` 精出** | 更低成本试跑 | 复杂多镜头或多机位重拍先出 `480p` 验口型/视线，过审再上 `1080p` |

## 二、2.5 核心避坑红线（BytePlus 2026-11 官方 FAQ 实证）
1. **严防“瞳孔异常发光”**：禁止写 `狂热 / 极度震惊 / 眼里冒火` 等过载情绪词；强冲击戏可加正向兜底 `眼神自然正常，无任何眼部发光特效`。
2. **按首次出场顺序编号上传**：多角色视频若上传顺序与首出场顺序不一致，极易张冠李戴；务必按首出场排序并在开篇逐一定义唯一角色标签。
3. **长时长防漂移（`>15s`）**：在 `15s` 后的关键时间段用 5–8 字极简复述主角核心特征（如“穿浅灰卫衣的少年”）。
4. **编辑/延长动词禁忌**：走编辑或延长任务时，直接写 `编辑 @视频1` / `向后延长 @视频1`，**绝不写“参考 @视频1”**，否则模型误判为普通全能参考任务！
5. **超 4 秒单拍允许 1 次平滑复合运镜**（如“缓推顺转微仰”），仍坚持克制反炫技。
