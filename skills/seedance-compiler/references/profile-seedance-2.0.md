# 模型适配器：Seedance 2.0 兼容降级规范（BytePlus 2026-11 官方对齐）

> 当项目或平台入口受限需回退至 **Seedance 2.0** 时严格按本适配器编译，**严禁混入 2.5 的精确时间戳语法**。

## 一、Seedance 2.0 硬参数与与 2.5 的关键差异

- **单次时长**：`4–15 秒`（`SEQ-Multi` 多镜头连拍甜区 `8–15s` / `2–3` 切；`M-Master` / `S-Struct` 单镜 `4–10s`）。
- **素材硬上限**：图片 `≤9 张`、视频 `≤3 个`（合计 `≤15s`）、音频 `≤3 个`（合计 `≤15s`）、总文件 `≤12 个`；**推荐甜区 3–5 个素材**（严禁塞满上限稀释注意力）。
- **与 2.5 的四大硬隔离红线**：
  1. **严禁精确时间戳（`0s-3s` / `0-3秒` / `[0-2s]`）**：2.0 不响应精确时间戳，强写易跳变，**必须使用 `镜头1：` / `镜头2：` / `镜头3：`** 编排多镜头顺序；
  2. **严禁三视图进视频**：2.0 喂传统全身三视图极易克隆双胞胎（`ERR-007`）；尽量用 `SHOT-MASTER` 单人单视角首帧起步，若用 `@角色设定卡`（`CHAR-SHEET`）须显式写明仅取右半幅五官特征；
  3. **单镜单一运镜**：每个切镜只给 1 种明确运镜（不可同镜叠写“推+摇+环绕”）；
  4. **超过 4 人严禁裸传角色图**：超过 4 位角色须先在 `Seedream 5.5` 合成群像首帧，视频阶段只喂首帧 + 干声。

## 二、Seedance 2.0 纯净模板

### 1. `SEQ-Multi` 多镜头连拍模板（`8–15s` / `2–3` 切）
```text
@实景空景或开场首帧 锁定本场真实空间、暗暖光比与原有摆设；将 @图2 定义为[角色A]（音色使用 @音频1 [声学特征]）；将 @图3 定义为[角色B]（音色使用 @音频2 [声学特征]）。

镜头1：[景别焦段与单一运镜]。[主光源与光照-皮肤交互]。[角色A 2D位置、三层朝向锁与物理后果链]，[角色A]用[声态]说：{[短句台词1]}。

镜头2：干脆硬切[反打景别焦段与单一运镜]。[角色B 2D位置、三层朝向锁与镜内情绪微转折]，[角色B]用[声态]回击：{[短句台词2]}，句尾保留一秒沉默微动余韵。

全程保留<[真实房间底噪与动作拟音]>。全程无背景音乐，无字幕，无水印，画面流畅无闪烁，五官与光影前后一致。
```

```text
@母帧或首帧 为首帧起点，参考 @角色设定卡 右半幅五官保持[角色]面部与衣着连戏，音色使用 @干声_情绪档 [声学特征]。

镜头1：[沿用首帧景别与单一运镜]，完整延续首帧真实空间墙面与实用光比。第0秒从首帧闭唇蓄势态自然启动：[物理微动、停顿气口与动作后果链]，自然张口说：{[台词]}，尾音落定留约一秒沉默呼吸余韵，眼神绝不看向镜头。

全程保留<[真实底噪与同步拟音]>。全程无背景音乐，无字幕，无水印，画面流畅无闪烁，五官与光影前后一致。
```
