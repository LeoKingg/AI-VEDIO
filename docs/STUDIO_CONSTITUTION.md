# AI-VEDIO V3.0 总调度宪法（Showrunner Constitution）

> **定位**：总调度（Showrunner）与 7 位专职子 Agent 剧组的最高协作协议。解决单脑创作“顾此失彼、规则互搏、盲抽烧预算”的系统性问题。

---

## 一、冲突裁决优先级宪法（不可逾越）

当不同专职工位提出冲突要求时（例如表演指导想加 3 层微表情细节、编译器要求控字数、美术要求保留桌沿碗筷、摄影要求裁掉空椅），总调度按以下三层硬排序一票裁决：

1. **`P0` 物理、模型与合规底线（绝对否决权）**
   - 零画风跳变（严禁外来 `STYLE-REF` 进视频；全片同源实景派生）；
   - 零穿帮几何（可见在场座位 100% 坐实或裁出画外；`S0→S1` 物理道具成对守恒）；
   - 零模型自杀语法（生图 `≤260` 字、零视觉否定词堆砌、零图文人数对抗、零钟面词/粉红大象泄漏、2.5/2.0 语法严格隔离）；
   - 零平台风控违规（30 天同账号人脸信任闭环、严禁外部第三方修图压缩写实人脸、避开审核敏感词）。
2. **`P1` 叙事连戏与观众留存（次高优先级）**
   - 黄金 3 秒视听双钩 + 每 12–15 秒情绪/信息转折；
   - 跨幕 4 维交接连戏（妆容泪痕汗渍、情绪心理转折弧、站坐姿态、道具状态）；
   - 相邻同角色镜头拉开景别/构图防跳剪；
   - 音画同步与情感匹配（干声情绪档位匹配当前戏份）。
3. **`P2` 表演、运镜与质感加分项（在满足 P0/P1 前提下最大化）**
   - 动机驱动运镜、Z 轴纵深调度、前景偷窥遮挡、微停顿呼吸感、胶片暗调层次与后期院线抛光。

## 二、1 总调度 + 7 专职子 Agent 三波流水线协议

每个专职 Agent 严格绑定对应 `skills/` 下的唯一规范手册（1:1 映射），不得越权修改其他工位产出：

| 波次 | 执行模式 | 参战工位（Skill） | 强制输入契约 | 唯一交付物与锁死内容 |
| :---: | :---: | :--- | :--- | :--- |
| **第 1 波**<br>定底座 | 串行<br>（上游锁下游） | **站 1** `director-showrunner`<br>→ **站 2** `cinematography-blocking`<br>→ **站 3** `art-asset-pipeline` | `00_project_brief.md`<br>`presets/`<br>上一幕末镜原文（`N≥2` 必读） | ① Step 0.5 拍板剧本 + **5 模生成路由表** + 跨幕交接卡 + 四轨声景表<br>② 360° 导演平面图 + 2D 画面坐标 + 安全区校验<br>③ 视觉圣经 + `manifest.json` + Seedream 5.5 资产/母帧/线稿分镜 + **0 积分动态预演（Animatic）** |

### 精准点将模式（单点故障外科技手术）
成片验收出现局部问题时，**绝不重跑全流水线**，由总调度按错因只唤醒 1–2 个对应工位：
- 节奏拖沓/连戏断层 → 仅唤醒 **站 1**；
- 穿帮空椅/构图遮挡/越轴/字幕压脸 → 仅唤醒 **站 2**；
- 画风跳变/人脸漂移/道具变样 → 仅唤醒 **站 3**；
- 演技僵硬/笑场/音色平淡 → 仅唤醒 **站 4**；
- 提示词不听话/镜头乱切 → 仅唤醒 **站 5 + 站 6**；
- 局部微瑕可救片/调色超分包装 → 直接由 **站 7** 闭环处理。

## 三、预算、草稿试拍与抽卡止损铁律

1. **Pre-Vis 先行（0 视频积分验节奏）**：每幕在消耗任何视频积分前，先拿关键帧/黑白分镜草图 + 粗配音在剪映铺一版时间线动态预演，确认 3 秒钩子、每句对白秒数与切点节奏无误后再开机。
2. **锚点先行 + 草稿试拍（Draft-First）**：
   - 每幕不一次性全抽，先挑 **3–4 个核心定调锚点**（建立/多镜对话/特写情绪/复杂结构）跑通；
   - **`Seedance 2.5` 主力策略**：复杂多镜头序列或多机位重拍，优先以 **`480p` 低价草稿试拍** 验证构图、口型与节奏，验收通过后再原参数切 `1080p`（或 `draft/complete`）精出；
   - **锚点视频反哺**：首个过审高分视频立刻固化为本场标杆，下游同场景镜头可按需挂载其为 `@Video` 影调/动态参考（注意严格声明“仅参考光影色温/运镜节奏”）。
3. **两击止损红线（2-Strike Rule）**：
   - 同一 Prompt 连续 2 次抽卡出现**同类结构/眼神/物理缺陷**，**立刻停手严禁盲抽第 3 次**！
   - 必须立刻切换工程手段：生图侧切「同图单轮局部微调」或「外挂无字黑白草图」；视频侧切「5s 自拍 `@Video` 参考」或「拆解/降维模式」或「原生局部编辑」。
4. **跨幕母帧与资产复用最大化**：凡同空间固定机位特写母帧（`SHOT-MASTER`）与主角多情绪档干声，统一登记在项目 `manifest.json`，全剧跨幕直接复用。

## 四、唯一真相源（SSOT）与可插拔预设规范

1. **规则零重复**：全仓库每条工程规则只在其主责 Skill 或唯一总文档中定义一次，其他文件仅做引用，彻底杜绝多头修改导致的规则脑裂。
2. **题材与平台物理插拔**：通用电影工业内核严禁硬编码单一题材审美或单一平台画幅；具体题材美学（摄影机/胶片/色彩签名/灯光配方）统一读取 `presets/genre_*.md`，分发画幅与 UI 安全区统一读取 `presets/platform_*.md`。
3. **项目状态由 `manifest.json` 驱动**：每个项目维护轻量级 `manifest.json`，记录当前模型、预设、角色与多情绪干声、道具与 `S0→S1` 成对 State Diff、粉红大象禁词表（`removed_objects`）及跨幕母帧清单，供 `lint_prompt.py --manifest` 自动执行跨文件一致性校验。
