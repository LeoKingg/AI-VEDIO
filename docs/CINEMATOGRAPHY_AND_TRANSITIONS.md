# 导演摄影、空间几何与视听转场规范（V3.0）

> **核心升级（0→1 到 1→100）**：在保住零穿帮底线的前提下，告别“全片 80% 死板固定机位 PPT”，系统性引入**动机驱动的电影运镜调度、序列内切镜节奏、听者优先与视觉潜台词、双层坐标系隔离、视锥邻座守恒与平台安全区校验**。

## 一、1 → 100 电影镜头语言与场面调度

### 1. 景别 = 情绪距离（景别阶梯法则）
- **远景/全景（24–35mm）**：立空间秩序、展示人物孤立感与权力站位。
- **中景/中近景（35–50mm）**：双人关系与多镜头连拍（`SEQ-Multi`）主力景别。
- **近景/大特写（85mm）**：**全场重锤，限用 2–3 个决定性瞬间**，留给态度骤变、真相揭露或无声落泪。
- **相邻防跳剪铁律**：相邻两镜若拍同一角色，**必须拉开景别或机位角度**（例如 85mm 紧越肩中近景 → 85mm 5° 微倾单人紧逼特写），严禁相邻两镜复用同一张同景别母帧硬切。

### 2. 动机驱动的电影运镜（告别死板固定，也拒绝盲目炫技）
> **原则**：**固定机位是冷静基准（占约 40%–55%），其余 45%–60% 必须按情绪推进与空间动作配置有动机的电影运镜**；单镜内仅做 1 个主运动（2.5 超 4s 拍可做 1 次自然复合衔接），高难复杂运镜直接调用 **`V-Ref` 参考视频**复刻。

| 运镜 / 调度技法 | 情绪与叙事动机 | 适用模式 |
| :--- | :--- | :--- |
| **极缓推镜 / 拉镜** | 心理压迫递增、真相刺痛 / 孤立抽离、无力释怀 | `M-Master` / `SEQ-Multi` |
| **Z 轴纵深调度** | 人物沿前后景深走近或远去，用物理距离变化外化关系破裂或逼近（远比横排站桩有电影感） | `SEQ-Multi` / `S-Struct` |
| **焦点转移（Rack Focus）** | 视线从前景关键道具/虚化人物平滑移焦至后景听者微表情，一镜完成因果揭示 | `2.5` `SEQ-Multi` / `M-Master` |
| **过肩正反打（OTS）** | 强化双方视线交锋与空间贴近感（仅在全景物理距离合理时使用；前景虚化肩背不可加挂该人全身图防转头） | `SEQ-Multi` / `S-Struct` |
| **前景遮挡与擦拭（Peek & Wipe）** | 透过门框、桌角、杯盏、他人肩背窥视，制造偶然目击真实感；人物走过前景可作自然遮挡转场 | `SEQ-Multi` / `SEQ-Grid` |
| **微荷兰角（5°–8°）+ 缓推** | 心理防线瓦解、理亏窒息、突发震惊（现实主义慎用 >10° 大斜角） | 高潮前压迫节点 |
| **30°–60° 低角弧线绕推** | 弱者反击、尊严觉醒、全场唯一情绪核爆点（“标点符号式运镜”） | 全幕唯一 `CLIMAX` |
| **一镜到底（Oner）与多机位重拍** | 连贯空间内情绪一口气顶到底；或 2.5 先拍 1 条完美锁定表演再 `E-Edit` 多机位重拍 | `2.5` `15–30s` / `E-Edit` |

### 3. 1 → 100 叙事三大高级习惯
1. **视觉潜台词预算（Show Don't Tell ≥ 30%）**：绝不让台词复述画面已经演出来的事；用动作（把碗重重放下、默默替人挪椅子、盯着空位发呆）替代大段解释性对白。
2. **听者优先（Listener-First）**：每场关键重锤台词落地，必须设计切向**挨骂、被刺痛或冷漠回避的听者反应**，打破廉价短视频“谁说话拍谁”的机械感。
3. **张力一张一弛**：一场戏只有一个最高潮；爆发前留 `1–2s` 安静缓冲，爆发后留 `0.8–1.2s` 情绪余韵与释放出口。

## 二、双层坐标系隔离与视锥邻座守恒铁律（彻底根治空间穿帮）

### 1. 双层坐标系严格分离（永久铁律）
- **导演层（仅用于分镜表、平面图与红线审计）**：使用 **360° 房间钟面坐标**（如 `12点窗 / 9点墙 / 8:30 主角A / 3:30 主角B`）锁死绝对物理方位与轴线，防止越轴与门洞漂移。
- **模型层（发给 Seedream 5.5 与 Seedance 2.5/2.0 的一切 Prompt）**：**严禁出现任何钟面方位词**（防止 3D 世界坐标与 2D 镜头画面坐标失配，及中文“8点半/10点”触发时间先验劫持），必须 100% 翻译为 **2D 画面空间四要素 + 三层朝向铁锁**：
  1. **画幅区块与从左到右排序**（前景/中景/背景、左三分之一/居中/右三分之一）；
  2. **景深遮挡与裁切边界**（虚化前景占比、左右边缘切在何处）；
  3. **背景按物理实景直译**（如“身后为素净冷暗米灰墙面 / 深色落地窗帘”，禁写“9点墙/12点窗”）；
  4. **三层朝向铁锁（凡非正视镜头必写）**：① **躯干朝向**（微侧向左/右）→ ② **头部角度**（三分之二侧脸/正侧面，显式覆盖定妆图正脸惯性）→ ③ **视线落点**（水平越过画左/右边缘盯向画外某侧或低看面前物件，默认**严禁看向镜头**）。

### 2. 机位视锥与在场座位守恒法
- **先拉视锥线、再定景别（连人带椅留 `≥10°` 安全余量）**：从机位在平面图拉出左右视野边界，**必须按在场人物肩宽/椅背外缘计算，禁止 `0.2°` 贴边点坐标假裁切**；且机位瞄准中心角必须与 `2D` 画面横坐标百分比数学联动一致（绝不允许瞄准角落却要求桌面中心道具摆到画面 `20%–35%` 处）。凡视锥扫到的邻近区域，若剧本设定已有角色在场，只能二选一：
  - **方案 A（坐实入画）**：用浅景深虚化邻座人物剪影、前景虚化肩背或碗边衣袖手背实拍坐实；
  - **方案 B（物理裁出画外）**：收紧焦段（`50–85mm`）或改用**平桌微仰视角（使远端桌面与对侧椅子处于下缘之下）**将邻近座椅彻底推出视锥之外。**严禁在 24–50mm 跨桌俯拍时宣称“靠裁切避开位于核心道具正后方的对侧座位”**。
- **禁写模糊断桌词**：严禁写“露出四分之一桌角”导致模型误把近端座位截成远端角座；必须按主角自身左右手拆清“左手边延续的桌段坐着谁 / 右手边是桌沿边界”。

### 3. 平台安全区前置硬校验
每张构图与母帧必须对照当前项目的 `presets/platform_*.md`（横屏黑边安全区或 9:16 竖屏右侧 UI / 底部字幕避让区），确保核心眼神、手部动作与道具不被字幕或平台点赞栏遮挡。

## 三、序列切镜与跨场前置转场规范

1. **同场情绪原子优先走 `SEQ-Multi` / `SEQ-Grid`**：同一空间、连贯升温的 2–4 个切镜直接合并为 1 条 `10–25s` 原生多镜头序列（`2.5` 用连续整数秒 `[0s-4s]`，`2.0` 用 `镜头1/2/3`），内部用 `[切至]` / 明确硬切指示，天然统一光影与房噪。
2. **必须拆为独立单元的硬边界**：跨越不同物理空间、发生 180° 视角大反转、或需要完全不同的参考图组合（如车内 ↔ 车外、超 4 人满座全景 ↔ 80° 纯手部顶拍）。
3. **跨单元接点咬合 + 4 大电影转场**（禁用廉价炫光/翻页花字）：
   - **动作匹配切（Cut on Action）**：前段尾 `0.5–1.0s` 预埋下一动作 20%–30% 起势，后段第 0 秒直接进动态（禁静态冷启动）；
   - **J-Cut（声先画后）**：下一场标志性音效或起首台词提前 `0.15–0.5s` 垫入上一场结尾；
   - **L-Cut（声延画切）**：上一场尾音/呼吸延续进下一场空景前 `0.3–0.8s`；
   - **枕镜呼吸切（Pillow Shot）**：大幕情绪落地后留足 `0.8–1.2s` 沉默微动余韵或 `1.5–2s` 无人空景消化情绪。
