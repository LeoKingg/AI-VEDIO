# AI 视听制作实战错误复盘与避坑库（V2.0 重构版）

> **使用方式**：每条错误均标注**生命周期状态**与**适用模型边界**，避免旧模型补丁永久固化或误伤新模型能力。  
> **状态标签**：
> - `CORE-PERMANENT`：底层视听/物理/制片规律，跨模型永久生效；
> - `UPGRADED-IN-V2`：第一部剧暴露出的双刃剑问题，已在 V2.0 从架构根源升级解决；
> - `MODEL-BOUND`：与特定模型版本强相关的限制，随适配器分流管理。

## 二、典型高危错因拆解（核心细节速查）

### `ERR-002`｜纯白平光参考图稀释暗调光比 + 平静头肩照引发“肌肉锁死”
- **现象**：绑定纯白 `#FFFFFF` 平光人物图与平静面部特写后，角色喊叫声嘶力竭但面部无泪僵平，暗调电影光被整体洗灰成电视剧平光；挂载无需露脸的背景人物图还会逼迫模型强行拉远景别。
- **根因**：多模态视觉编码器会继承参考图的光比与表情权重；无关参考图会倒逼模型把它塞进构图里。
- **V2.0 铁律**：① 进视频的 `CHAR-VID` 统一用中灰底 `#555A64` + 45° 定向侧光；② 强爆发戏严禁挂载平静头肩照，改用 S 级情绪剧照首帧驱动；③ 画面不露脸的角色严禁挂参考图、严禁在 Prompt 提其名字。

### `ERR-007`｜多人全景喂三视图触发人物克隆
- **现象**：多人餐桌戏喂入含 3 个同款形象的三视图，AI 自动复制分身把 6 人画成 7 人，且配角静止如蜡像。
- **V2.0 铁律**：三视图只做 `CHAR-BASE` 母档；**凡 2 人以上视频任务一律喂单人单视角图（`CHAR-VID`）**，并在正文明确硬人数上限（如“画面中严格共计 6 人”）+ 给配角写入具体反应微动。

### `ERR-008`｜劈开完整情绪原子 + 虚构前景肩导致冷启动断层
- **现象**：将同一空间内一口气爆发的“吼叫 → 甩围裙离席”硬拆成两条视频，且特写强行虚构了贴近镜头的前景肩，拼在一起后距离突变且动作冷重启。
- **V2.0 铁律**：同空间连贯情绪爆发打包进一条连续视频；开拍前确认全景真实距离（相距 2.5 米绝不在特写硬塞前景肩）；相邻两段在前段结尾预埋 20%–30% 起势、后段第 0 秒直接进动态。

### `ERR-011`｜极端动态截帧喂给同机位视频触发“姿态粘滞冻僵”
- **现象**：截取双手悬空、张大嘴的动态帧作为参考图去续拍同机位下一段，导致人物双手悬空定格 2–4 秒不动。
- **V2.0 铁律**：截帧反锁只选**自然放松静态帧**（手稳放桌面/方向盘、闭嘴正常坐姿）；带人物截帧优先用于切换新机位时的服装光色参考，同机位续拍回退到纯净空景 + 单人图。

### `ERR-012`｜车内多窗 90° 透视强转致挡风玻璃融化
- **现象**：喂正向前视车厢图却要求向左看敞开车门外，导致前挡风玻璃扭曲融化成侧门洞、人物瞬移到车头。
- **V2.0 铁律**：车内外参考图物理隔离，严禁混挂；优先采用**车外左侧平视 + 车门外 3/4 朝内 85mm 近景**避开 90° 拐角；非开关门镜写死车门全程保持敞开静止与 A 柱/车框刚体不变形；复杂车内机位强制先在 `Seedream 5.5` 出同角度 S 级首帧。

### `ERR-015`｜风格锚与空景重复挂载，且没交代空景与人物、机位的关系
- **状态 / 适用范围**：`CORE-PERMANENT`
- **具体案例**：mama-birthday / 第一幕 / `U01B`。同时绑定 `@风格光影锚_餐厅夜` 和 `@餐厅夜景空景`（后者本来就是参考前者生成的），正文又写成“延续 A 与 B 的左侧墙面”，结果光影描述重复，父亲坐在空景哪个位置、机位从哪边拍都没写，用户实测出片效果差。
- **第一性原理根因**：同源参考图重复挂载会稀释权重、挤占名额；空景只被当成“背景贴图”，模型拿不到人物位置、机位方向和近景下背景该露哪一块。
- **即时急救与永久预防**：已绑定空景的单元删掉风格锚；正文写明“人物在空景哪个位置、朝向哪边 + 机位从哪拍向哪 + 背景露出哪一块 + 不复刻全景构图”。已同步更新 `VISUAL_BIBLE_GUIDE.md` 和 `profile-seedance-2.0.md`。
