# 1 → 100 表演导演手册：潜台词、镜内转折与物理后果链

> **核心差距**：0→1 解决的是“不写崩溃/大哭等禁词”；1→100 解决的是**“让观众忘掉这是 AI，真切感受到人心的刺痛、忍耐与反击”**。

## 一、从“单态贴标签”升级为「镜内三拍表演弧」
哪怕只有 4–5 秒的特写，真人也不会从头到尾挂着同一张脸，必须设计 **起势态 → 触发微反应 → 情绪落点** 三拍：
- **示例（被拍桌惊吓后硬顶）**：第 0 秒闭唇蓄泪 → 受拍桌余威肩头本能轻颤一滞并喉结急咽半口气 → 咬紧发颤下颌压回哭腔、睁眼盯左微哑顶回 → 说完抿唇微喘死盯 1 秒。
- **示例（理亏强撑词穷）**：先强撑侧脸微仰 → 听到追问瞬间目光仓皇滑向桌面瓷碗 → 喉结干吞、手指不安轻搓桌沿 → 低哑含糊搪塞后垂眼僵坐。

## 二、动作 → 物理后果链（Seedance 2.0/2.5 真实物理引擎最吃这一套）
单写动作往往漂浮发虚，写清**动作引发的真实物理反馈**立刻拥有院线实拍重量感：
- ❌ 弱：`爸爸生气地拍了一下桌子站起来`
- ✅ 强：`右掌干脆狠拍胡桃木桌沿，震得面前白瓷碗与竹筷明显跳震发响，餐椅木腿向后刮擦地板退开，男人借势霍然起身`
- ❌ 弱：`她难过地放下杯子`
- ✅ 强：`玻璃杯底轻磕木桌发出一声闷响，杯内茶面微晃，她松开微微泛白的指节缩回膝上`
- ❌ 弱：`他在寒夜停下脚步`
- ✅ 强：`皮鞋踩在湿沥青上骤然停步，他低头吐出一团清晰白气在冷空气里散开`

## 三、禁用抽象情绪大词 → 高张力物理替代速查（防浮夸假笑、防 2.5 发光眼、防面瘫）

| 严禁直接写 | 替换为摄像机可见的高张力生理细节（选 2–3 项组合） |
| :--- | :--- |
| **彻底崩溃 / 歇斯底里 / 嚎啕大哭** | 眼眶泛红蓄泪、下颌发颤、胸口急促起伏、声带微哑带哽咽开口、尾音落定热泪沿颊滑落 |
| **满腹委屈 / 悲伤难过** | 眼眶泛红微湿、嘴角向下轻收、喉结急咽一口、视线躲避垂向桌面、指尖无意识攥紧衣角 |
| **心灰意冷 / 冷漠如水** | 原本舒展的嘴角一寸寸平复静止、眼神平沉不动、闭唇沉默停顿两秒、肩背微微松沉 |
| **压抑愤怒 / 暴跳如雷** | 眉心紧绞深纹、腮帮咬肌绷紧、下颌微抬前倾、指节攥白或手掌拍桌震碗、低沉咬牙压声喝斥 |
| **极度震惊 / 狂热（2.5 发光眼高危词）** | 抬到半空的手骤然顿住半秒、呼吸停滞一瞬、嘴唇微张无声停顿、眼神保持自然正常不发光 |
| **微微一笑 / 冷笑敷衍** | 禁空洞假笑；敷衍改写“双眼睁开斜睨、嘴唇平直绝不扬起、手搭碗边漫不经心开口”；苦笑改写“一侧嘴角极轻牵动两毫米随即收平并垂眼低看桌面” |
