# 四轨声景工程与主角多情绪档干声库规范

## 一、主角多情绪档干声库（根治 `ERR-027` 情绪拉平）

BytePlus 官方实测证实：**干声的情绪与语速必须与当前戏份接近**，拿一段平淡读白干声去驱动哭喊/怒吼高潮，模型会被干声拽回平淡腔调。

为核心主角在开机前（或分幕前）各录/准备 **1–3 档 5–10 秒纯净无杂音干声**，登记进 `manifest.json`：

| 情绪档位 | 资产命名约定 | 适用戏份 | 正文声学强化配套写法（不可省略） |
| :--- | :--- | :--- | :--- |
| **平静叙事档** | `@[角色]干声_平静` | 日常对话、隐忍敷衍、冷静试探 | `使用 @[角色]干声_平静 低沉平缓略带微哑的中年男声说：{...}` |
| **压抑隐忍档** | `@[角色]干声_压抑` | 强忍委屈、发虚搪塞、压火警告 | `使用 @[角色]干声_压抑 带着未消鼻音、紧绷克制的8岁童声顶回：{...}` |
| **情绪爆发档** | `@[角色]干声_爆发` | 拍桌怒喝、含泪嘶喊、全场高潮 | `使用 @[角色]干声_爆发 声带微哑却滚烫带哭腔颤音的8岁童声呐喊：{...}` |

> 轻量配角（全剧仅 1–2 句台词）可不录干声，直接用精准 5 维声学描述（年龄 + 音高 + 音色质地 + 语速节奏 + 情绪腔调）由 Seedance 2.5/2.0 原生直出。

## 二、原生一体音画 vs 后期精配决策树

| 场景 | 推荐路线 | 原因与操作要点 |
| :--- | :--- | :--- |
| **短句面对面对白（单句 ≤18 字）、带喘息哭腔的强情绪实拍感镜头** | **Seedance 原生一体音画** | 呼吸、喉结吞咽、嘴型与动作拟音同帧共生，真人感最强 |
| **画外独白、电话对讲音、超过 25 字的长段台词、严格商业配音腔** | **生成无口型/背影/空景画面 + 后期精配贴轨** | 避免长独白后半段口型漂移，后期可自由加电话滤波与精确卡点 |
| **高难多音字 / 生僻字 / 易吞音字** | **原生 `{台词}` 内用常见同音字替换** | 例：`螭龙山` 改写为 `{吃龙山}`，后期字幕仍按正确汉字压制 |

## 三、官方四类音频/字幕分隔符硬标准
- **人物台词**：`{台词}`（严禁遗漏，避免动作描述被误念成旁白）
- **环境与动作拟音**：`<音效>`（例：`<响亮拍桌木响、瓷碗筷震动脆响与餐椅后蹭地板声>`）
- **背景音乐（仅当确需模型原生生成音乐时用，剧情短剧默认禁用）**：`(音乐)`
- **画面字幕（剧情短剧默认严禁原生生成，留后期统一压制）**：`【字幕】`
- **静音指令铁律**：Seedance 原生同出音画，**不写静音约束就会被模型随机加廉价配乐**；剧情短剧每条尾句必写 `全程无背景音乐，无字幕，无水印`。
