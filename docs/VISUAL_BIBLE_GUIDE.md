## 一、底层物理法则：为什么“同源派生”决定画质天花板？

1. **外来风格图进视频 = 画风跳变元凶**：外来氛围图（`STYLE-REF`）与真实房间空景的墙色、木纹、反光率与胶片 LUT 存在不可调和的像素差异。将“灰底人像 + 外来风格图”喂给视频模型，必然导致人物近景与实景中景拼在一起像换了剧组（`ERR-021`）。
2. **白底平光稀释暗部**：视觉编码器会吸收参考图的亮度分布；纯白 `#FFFFFF` 平光图会把暗调电影光洗灰洗平（`ERR-002`），因此进视频/合成首帧的单人图与面部特写必须统一采用 **中深冷灰底 `#555A64` + 定向侧光**。
3. **单一真相源（SSOT）派生链**：
   `STYLE-REF（仅生图烘焙） → SCENE 空景（S0） → 局部编辑 SCENE-S1（成对物理守恒） → 全剧所有 SHOT-MASTER 实景母帧 / S-Struct 首帧 / 多关键帧`。
   全片每一个镜头都从同一套真实房间空景基因长出，才能达到院线级色彩与空间统一。

## 二、每部新剧开机必立的《视觉圣经》5 要素

写入 `projects/<项目名>/01_visual_bible.md`（先选定 `presets/genre_*.md` 与 `presets/platform_*.md`，再填本剧专属设定）：

1. **色彩签名与情绪分区**：为全剧每个空间/情绪阶段锁定阴影偏色、高光色温与暗部占比（避免泛写“电影感”）。
2. **实用光源铁律**：一切光线必须来自画内或画外真实物理光源（老式吊灯、窗外街灯、阴天窗口、日出侧逆光），禁用无源影棚面光。
3. **光学与胶片签名**：锁定机身、焦段分工（24–28mm 空间压迫 / 35–50mm 叙事中景 / 85mm 近景剥离）与胶片微颗粒，**禁用 `8K`、`超高清`、`大师杰作` 等吹水词**。
4. **服化防串色表**：同框或相邻正反打角色，服装必须在明暗与冷暖色相上拉开显著区隔，防止多模态模型跨角色串色。
5. **同账号 30 天写实人脸免风控闭环**：所有含写实人脸的资产必须在即梦 `Seedream 5.5` 同账号内部生成、局部精修并存入资产库——**严禁用外部 PS/美图修图压缩后再上传**（外部重压或超 30 天会触发写实人脸拦截）。

## 四、单空间纯净空景（`SCENE`）六要素验收铁律

1. **单空间纯净去耦**：只呈现当前独立空间，非主视角门洞留纯暗阴影或中性门框，严禁混入隔壁房间强特征家电（如餐厅露双开门冰箱/灶台）。
2. **明确主光方向与高光比**：有清晰明暗分区与物理投影，暗部沉稳不发灰、高光不惨白。
3. **统一单一调色签名**：冷暖分离克制，无杂乱彩色散景污染。
4. **光学透视准确**：建筑横平竖直、家具比例真实。
5. **空气感与生活磨损**：有真实居家痕迹与空间纵深，拒绝精装样板间塑料感。
6. **预留表演与构图空间**：绝对无人，但预留清晰站位、前景遮挡位与出画动线。

## 五、Seedream 5.5 生图四条第一性原理铁律

1. **短字数高信噪比（`≤260` 字，硬顶 `280` 字）**：只写「景别视角 → 多图显式分工 → 2D 站位与三层朝向 → 光影胶片」，严禁 450 字补丁散文。
2. **纯正向描写（视觉否定词硬上限 `≤1`）**：除“无字无水印”外，禁用成串“绝不复刻/严禁出现/绝无椅子”，全部改写为正向可见状态与精准裁切边界。
3. **零图文对抗**：画几人就绑足几个人的图；绝不喂高清带头人像却文字下令切头；复杂多人站位末位外挂无字黑白站位草图并写“成图清除所有草图线条与标记”。
4. **同图局部微调优先**：构图与光影对了 70% 立刻停抽，把底图喂回 `Seedream 5.5` 单轮只改 1 处（例如单修眼神朝向或补全桌面物体）+ 写全保留清单，拒绝整张盲抽。
