# V3.0 五模原生视频生成路由决策指南（Seedance 2.5 主力 / 2.0 兼容）

> **核心思维跃迁**：不再把一场 40 秒戏切碎成 11 个孤立 4s 单镜。先问“哪几个相邻切镜发生在同一空间、同一光影、同一情绪连贯流里？”，能合并进 1 次原生多镜头序列的绝不强拆！

## 一、5 模决策树（按从上到下优先顺序判定）

1. **是否属于“局部修改已有成片 / 单镜锁定表演后切多机位重拍”？**
   - 是 → 路由至 **`E-Edit`**（Seedance 2.5 原生时间戳局部编辑 / 延长 / 单镜多机位重拍，输出 `MOV`；复杂重拍先跑 `480p` 草稿测）。
2. **是否依赖极难文字复刻的电影级复杂运镜（希区柯克、大范围跟拍/环绕）或微妙真人表演停顿？**
   - 是 → 路由至 **`V-Ref`**（挂载 3–10s 电影运镜参考视频 / 5s 手机自拍表演视频 / 粗颗粒 3D 白模视频）。
3. **是否需要严格卡死 `>4` 人同框满座几何、高俯拍纯手部、或核心连戏道具精确交互？**
   - 是 → 路由至 **`S-Struct`**（单镜精确首帧或首尾帧；超 4 人时先在 Seedream 5.5 合成首帧锁死人数与站位，视频阶段不再同时塞 5 张单人图以防官方 `>4` 人克隆/少人陷阱）。
4. **是否属于同一空间、连贯升温的 2–4 切对话正反打或连续剧情推进？**
   - 若只需流畅切镜与自然调度（1–3 主体）→ 路由至 **`SEQ-Multi`**（主力首选：`2.5` 单条 `10–25s` 连续时间戳，`2.0` 单条 `8–15s` `镜头1/2/3`）。
   - 若需要严格控制每个切镜的特定构图（如蒙太奇/连环动作推进）→ 路由至 **`SEQ-Grid`**（`2.5` 优先用 `≤15` 格无字黑白线稿分镜或按序上传 `Image 1..N` 独立关键帧严格对齐）。
5. **是否属于跨镜/跨幕高频复用的固定机位特写、强情绪独白、或要求严控跨幕泪痕/老年肌理的独立重锤镜？**
   - 是 → 路由至 **`M-Master`**（同源 `SHOT-MASTER` 闭唇实景母帧 + `@角色设定卡` 提取右半幅大头五官 + 情绪档干声，零外来风格图）。

## 二、什么时候**坚决不强行合并**多镜头？（硬拆红线）
- 跨越不同物理房间或昼夜光影巨变（如暖黄餐厅 → 冷青玄关）；
- 发生 180° 空间大反转导致人物左右关系易翻车；
- 单段同时出现 `>4` 名需高清辨认的主角；
- 某镜含极高精度道具/纯桌面顶拍（如 80° 俯拍四副碗筷），合并易被模型自动拉远露脸（`ERR-002`）。

## 三、单场“混合最优编排”示例（40 秒餐桌对峙戏）
- **旧 V2.x 逐镜做法**：切碎成 11 个 4–5s 独立视频 → 11 次风格/光影/房噪接缝 + 13 张独立图。
- **V3.0 5 模最优做法（压缩至 5–6 个高质单元，切缝减半、影调浑然一体）**：
  - 单元 1（`SEQ-Multi`, 12s）：角色 A 拍桌起身喝斥 → 切带泪角色 B 惊颤硬顶 → 切站立角色 A 略仰压迫（3 切一次推理完成，同房同光同房噪！）；
  - 单元 2（`S-Struct`, 6s）：3 位长辈满座横移对照；
  - 单元 3（`S-Struct`, 4s）：右前景角色 B 控诉 + 4 座满员 vs 空位（5 人严控几何）；
  - 单元 4（`SEQ-Multi`, 12s）：长辈甲搭碗冷敷衍 → 切旁观亲友磕碗打发 → 切紧越肩角色 A 退缩（3 切连拍）；
  - 单元 5（`S-Struct`, 4s）：80° 满画幅纯桌面多碗数证；
  - 单元 6（`M-Master` / `V-Ref`, 12s）：角色 A 5° 微倾压迫词穷 → 切角色 B 30° 弧线绕推尊严核爆。
