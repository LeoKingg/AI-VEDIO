# 导演镜头语法、真实表演与视听转场规范

> **核心目标**：系统性补齐第一部剧暴露的三大视听短板——**① 镜头语言平庸缺少电影运镜、② 人物情绪 AI 感过重不够自然、③ 片段之间转场生硬**。本规范完全基于经典电影工业语法，不依赖任何单一 AI 模型。

---

## 一、导演镜头语法：每一个选择都必须有情绪理由

### 1. 景别 = 情绪距离（景别阶梯法则）
- **大远景 / 远景**：交代时空、衬托人物在庞大现实面前的渺小与孤独（常用于开场定场或爆发后的残酷抽离）。
- **全景**：锁定人物之间的物理距离与空间站位（谁坐主位、谁站边上、谁被困在角落）。
- **中景**：日常叙事与双人关系主力景别。
- **近景 / 中近景**：情绪开始升温、关系压迫感逼近的临界点。
- **特写 / 大特写**：**全场重锤，严禁批发**（每场戏最多 2–3 个决定性特写，留给态度骤变、真相揭露、关键动作道具或无声落泪）。
- **景别推进规律**：吵架/冲突升级时逐步收紧景别（全景 → 中景 → 近景 → 特写）；高潮爆发后突然退回远景或空镜，制造冷静、残酷的旁观余韵。

### 2. 运镜 = 情绪运动（反炫技铁律）
> **铁律：固定镜头是默认选择。没有情绪或叙事动机的运镜，一律砍掉。**  
> 严禁为了“显得高级”搞“9 镜 9 种运镜”的廉价 MV 炫技风——现实主义剧情片的电影感恰恰来自**极度克制的固定机位**与**精准克制的一次推近**。

| 运镜方式 | 物理动作 | 适用情绪与叙事动机 |
| :--- | :--- | :--- |
| **固定机位（默认）** | 摄影机纹丝不动 | 冷静观察、压抑窒息、日常对话、让演员微表情与台词本身发力 |
| **极缓推镜（Slow Push-in）** | 机位匀速缓慢靠近主体 | 心理压迫递增、下定决心、听见残酷真相时的窒息聚焦 |
| **极缓拉镜（Slow Pull-out）** | 机位缓慢远离主体 | 情绪释放、孤立无援、告别抽离、揭示被环境吞没的处境 |
| **克制手持微晃（Subtle Handheld）** | 真实肩扛呼吸级轻微晃动（非剧烈抖屏） | 纪实临场感、情绪濒临失控、争吵追逐、心理不安 |
| **平稳横移 / 跟拍（Lateral Track / Follow）** | 机位平行或侧后方跟随移动 | 陪伴感、行动决绝、在运动中交代空间流逝 |
| **过肩正反打（OTS）** | 前景虚化一方肩背，焦点落于对方 | 强化双人视线交锋与空间贴近感（**注意真实物理距离**：若全景两人相隔 2.5 米，特写绝不强塞紧贴镜头的虚假前景肩） |

### 3. 机位角度与构图心理学
- **权力角度**：平视 = 客观平等；**微仰拍** = 强势方/压迫感/尊严觉醒；**微俯拍** = 弱势方/被审视/疲惫困顿；**微荷兰角（5°–10° 轻微倾斜，现实主义慎用大角度）** = 心理失衡或突发震惊。
- **高阶电影构图（每镜选 1 种即可）**：
  - **框中框（Frame within a Frame）**：透过门框、走廊、车窗、货架缝隙拍人物，视觉化“被家庭/现实困住”的窒息感；
  - **大面积负空间**：把人物压在画面左/右三分之一处，留出大片暗墙或空路，传递孤独与疏离；
  - **前景半遮挡**：前景虚化的茶杯、桌角、门框、车头，制造“偶然目击”的偷窥真实感；
  - **镜面/玻璃倒影**：车窗、旧镜子中的人物侧脸，表达自我审视与内外割裂。

### 4. 对话戏灵魂：听者优先原则 + 张力弧线
- **听者优先**：情绪往往不发生在喊话的人脸上，而发生在**挨骂、被刺痛、沉默忍耐的那个人脸上**。每场关键台词落地，至少切 1–2 个听者反应近景。
- **张力一张一弛**：一场戏只有一个最高峰。**爆发前必须留一拍安静缓冲**（如停顿、吞咽、手指停住），**爆发后必须留释放出口**（沉默、空镜或拉远）；全程大喊大叫等于没有高潮。

## 二、根治“人物情绪 AI 感重”的三大实战原则

AI 演戏发假，90% 源于两个原因：① Prompt 写了抽象大词（“彻底崩溃、痛苦哀嚎、无比释怀”），模型只会按舞台剧模板把五官挤成一团；② 缺少真实人类表演里的**克制、停顿与次动作**。

1. **情绪必须翻译为“可被摄像机拍到的微弱物理变化”**：
   - 写“笑容一寸寸僵住，嘴角缓慢平复，喉结轻咽，视线从对方脸上移向桌面”，**不写**“她心灰意冷、彻底绝望”；
   - 写“指节慢慢攥白，胸口起伏加快半拍，下唇抿紧一秒后松开”，**不写**“她压抑着满腔愤怒”。
   - （完整现实主义物理词典见 `skills/seedance-prompt-writer/references/emotion-physics-lexicon.md`。）
2. **给表演留“次动作”与“真实停顿”（绝不站桩念词）**：
   - 真人吵架或隐忍时，手不会僵垂在身体两侧——会无意识摩挲杯沿、捏紧衣角、低头整理袖口、视线先避开再猛地抬眼。
   - 重要台词之前或之后，安排 `0.5–1.0 秒` 的**沉默气口**（闭唇倾听、深吸半口气、目光失焦一瞬），真人感立刻飙升。
3. **高难表演优先调用多模态武器**：
   - 声音漂移/念词腔：用主角预先锁定的 `VOICE-REF`（`@Audio`）稳住常态声线；高难电话音/画外音直接留给剪映后期独立贴轨（如《川藏线》U29 验证的零失误做法）。
   - 极难演的微妙神态转换：用手机自拍 5 秒自己的眼神停顿与微表情节奏作为 `@Video` 参考喂给 Seedance，省去 10 次纯文字抽卡。

## 三、根治“片段转场生硬”的前置视听设计规范

**核心认知：流畅的转场不是剪映里拖一个“叠化/闪白”特效，而是早在写分镜表时就把每一条素材的“入点”和“出点”咬合死。**

### 1. 划段铁律：按「完整情绪原子」划段，绝不在波峰劈刀
- 同一空间、同一光线、一口气顶到底的情绪连续动作（如“质问尾音接扯摔围裙离席”），必须打包进 **1 条连续视频单元** 内（如 6–10 秒双镜或一镜到底），严禁拦腰斩成两条独立视频制造 AI 冷启动断层。
- 跨视频的合法刀口只允许落在：**① 走出画外/切换空间、② 说话人切换至听者反应、③ 动作顶点接下一镜延续、④ 明确的时间跳跃**。

### 2. 同场相邻两段：强制写「接点状态咬合」封死冷启动
- **前段结尾预埋起势**：在上一条结尾的最后 `0.5–1.0s`，让人物做出下一动作的 20%–30% 起势（如喊完尾音立刻抬手抓围裙带、拉住手臂骤然急停回拧肩膀）。
- **后段第 0 秒直接进动作**：承接镜第 0 秒**严禁写中性站立起手**，必须从“正在回头/正在推门/眼中已蓄满泪”的饱满动态切入，剪辑时按**动作匹配切（Cut on Action）**裁掉冷启动帧，干脆硬切。

### 3. 跨场 / 跨幕转场：分镜表必选 4 大电影级转场技法
在《导演分镜规格表》里，每场结尾与下一场开头必须显式指定以下 4 种之一（禁用廉价炫光/翻页花字特效）：

| 转场技法 | 前期分镜与 Prompt 怎么预埋 | 后期剪映怎么拼 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **1. 声音先行（J-Cut）** | 下一场的标志性环境音或第一句台词（如急刹轮胎声、手机铃声、开门声、怒吼起音）提前准备干声/音效 | 下一场音轨比画面提前 `0.15–0.5s` 垫入上一场画面结尾 | 情绪打断、突然切入新时空、快节奏推进 |
| **2. 声音延留（L-Cut）** | 上一场结尾保留 `0.8–1.2s` 沉默表情或环境余响 | 上一场尾音/抽泣/关门回声延续进下一场空景的前 `0.3–0.8s` | 情绪余韵发酵、沉痛转折、内心独白衔接 |
| **3. 视觉/动作匹配切（Match Cut）** | 前镜结尾与后镜开头设计**相似构图形状或同向运动轨迹**（如：向右摔门出画 → 下镜从左向右快步走进新空间；手扔卡片下坠 → 高空俯拍卡片下坠） | 动势速度对齐、在动作最干脆处 0 帧硬切 | 因果强关联、时间快速压缩、蒙太奇段落 |
| **4. 枕镜 / 空镜呼吸切（Pillow Shot）** | 情绪大幕结尾预留 `0.8–1.2s` 静默余量，必要时插入 1.5–2s 无人空景（风吹窗帘、黑夜路灯、静止餐桌） | 伴随环境底噪自然淡入淡出，给观众消化情绪的呼吸口 | 大幕切换、时间跨度（如“半年后”）、克制留白 |

### 4. 镜尾呼吸余量硬规矩
凡情绪句尾或场次结尾镜头，**生成时长必须比目标精剪时长多预留 `0.8–1.2 秒` 的无台词静态/微动余韵**（如沉默对视、眼泪滑落、背影渐远），彻底告别前期卡死秒数、后期被迫 `0.75x` 硬降速救场的窘境。
