# 模型适配器：Seedance 2.0 专属语法与硬约束

> 当目标生成模型为 **即梦 Seedance 2.0** 时严格按本文件编译，**严禁混入 Seedance 2.5 的时间戳或多关键帧语法**。

## 一、官方技术边界（2.0 硬参数）

- **单次时长**：`4–15 秒`（推荐甜区：`4–10 秒`，1–2 个同空间镜头）。
- **素材硬上限**：图片 `≤ 9 张`、视频 `≤ 3 个`（合计 ≤ 15s）、音频 `≤ 3 个`（合计 ≤ 15s）、总文件 `≤ 12 个`；**音频不能单独提交，必配至少 1 张图或 1 个视频**。
- **推荐素材甜区**：**总计 3–5 个素材最佳**（如：S 级首帧 1 张；或 A 级常规镜 = 1 张纯净空景 + 1–2 张中灰底单人图 + 1 张 `STYLE-REF` 光影锚 + 1 段主角干声）。
- **模式互斥**：**首尾帧模式** 与 **全能参考模式** 不可混用（S 级单图首帧如不需挂额外音视频，直接走首尾帧入口最稳；如需挂载 `@Audio`/`@Video` 或多图，走全能参考并在首句写明 `@首帧图 作为开场首帧`）。
- **核心语法限制**：
  1. **严禁精确时间戳**（如 `0s-3s`、`0-3秒`、`[0-2s]`）——2.0 不响应时间戳，强写易导致画面跳变或报错，必须用 **`镜头1：` / `镜头2：`** 序号编排。
  2. **单镜单一运镜**：每个镜头只给 1 种明确克制运镜（或固定机位）。
  3. **多人镜严禁三视图**：2.0 喂三视图给多人场景极易克隆分身（`ERR-007`），只允许传单人裁切/中灰底单人图 `CHAR-VID`。
  4. **按出场顺序绑定 `@` 资产**：粘贴进即梦后须删纯文本 `@xxx`，通过输入框自带 `@` 弹窗重新点选绑定。
