# 电影镜头语法：情绪翻译速查表

每一项镜号选择必须服务于**人物关系与情绪推进**，绝不炫技。

## 一、景别 = 情绪距离

| 景别 | 画面范围 | 焦段参考 | 情绪功能 | 使用纪律 |
| :--- | :--- | :--- | :--- | :--- |
| **大远景 (EWS)** | 环境占绝对主体，人物渺小 | 24mm | 孤独、命运感、渺小、史诗释放 | 场次大建立、大结局抽离释放 |
| **远景 / 全景 (WS)** | 人物全身与完整空间关系 | 24–35mm | 交代站位与物理距离（站位即关系） | 双人/多人互动必先立空间基准 |
| **中景 (MS)** | 膝盖/腰部以上 | 35–50mm | 客观叙事、对话主力 | 日常交流与动作展开主力 |
| **中近景 / 近景 (MCU/CU)** | 胸部以上至肩颈 | 50–85mm | 关系逼近、情绪显形、压迫升温 | 对话升级与听者反应核心景别 |
| **特写 / 大特写 (CU/ECU)** | 面部、眼神、手部或关键道具 | 85mm 浅景深 | 情绪重锤、真相刺痛、关键抉择 | **全场限用 2–3 次，严禁批发** |

## 二、运镜 = 情绪运动（固定机位是默认）

| 运镜 | 物理动作 | 情绪动机 | 现实主义使用提醒 |
| :--- | :--- | :--- | :--- |
| **固定机位（默认）** | 摄影机完全静止 | 冷静目击、窒息压抑、让演技说话 | **全片 50% 以上镜头应保持克制固定** |
| **极缓推镜 (Slow Push-in)** | 机位匀速微推进 | 心理逼近、真相压迫、下定决心 | 推幅要克制，忌像 PPT 猛冲 |
| **极缓拉镜 (Slow Pull-out)** | 机位匀速微远离 | 孤独抽离、无力感、情绪释放 | 极适合留白收尾 |
| **呼吸级手持 (Subtle Handheld)** | 极轻微真实肩扛呼吸感 | 纪实临场、情绪失控边缘、焦虑 | 严禁剧烈晃动致画面糊帧掉帧 |
| **平稳跟拍 / 横移 (Track/Follow)** | 侧面或后侧随人物移动 | 陪伴前行、决绝离开、空间流动 | 保持单一方向，避免 180° 猛拐 |
| **过肩正反打 (OTS)** | 虚化一方肩背作为前景拍对方 | 强化对峙视线交锋 | **仅当全景两人真实距离较近时使用** |

## 三、机位角度与构图

- **角度 = 权力关系**：平视（平等纪实默认）；微仰拍（强势/压迫/尊严抬头）；微俯拍（疲惫/弱势/被审视）；微荷兰角 5°–10°（短暂心理失衡，现实主义慎用）。
- **高级构图（每镜挑 1 种落地）**：
  - **框中框**：门框、走廊、车窗、窗格围住人物 → 视觉化“被生活困住”。
  - **负空间（30%–50%）**：人物偏置画面一侧，大面积暗墙/空廊/天空留白 → 孤独与窒息。
  - **前景半遮挡**：桌角、茶杯、门框边缘、车头虚化压前景 → 真实偷窥目击感。
  - **玻璃/镜面反射**：车窗倒影、旧穿衣镜 → 内心割裂与自我审视。

## 四、光线物理写法（禁写情绪形容词）

- 禁写：“氛围很压抑”“光线很温暖有故事感”。
- 必写物理事实：
  - 顶光压眼窝：“头顶单盏暖黄吊灯垂直下压，额头微亮、眼窝沉在阴影里，四周墙角暗沉”。
  - 侧逆光离别：“清晨低角度金色阳光从人物右后方切入，勾亮发丝与肩线，正脸保留柔和暗部”。
  - 冷暖对照：“前景边缘透入客厅微弱暖黄余光，人物身后玄关浸在低照度冷青吸顶光里”。

## 五、对话戏铁律：听者优先原则

情绪往往不在喊得最大声的人脸上，而在**默默听着、被刺痛的那个人脸上**。每场重要对话，至少设计 1–2 个“说话者画外音 + 镜头给听者微表情反应”的切镜，立刻摆脱廉价短视频的“谁说话拍谁”机械感。
