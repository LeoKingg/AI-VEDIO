# 双层坐标系翻译与视锥邻座守恒操作手册

## 一、导演层 → 模型层无损翻译对照表（严禁钟面词泄漏）

| 导演层钟面描述（仅分镜/平面图用） | 模型层 2D 画面空间标准译法（发给 Seedream / Seedance） |
| :--- | :--- |
| `主角A在 8:30 拍桌，机位在 4:30` | `主角A坐在方桌左近端（居画面左侧三分之一），侧身向右前倾、三分之二侧脸朝右，直盯画外右侧` |
| `背景为 9 点素墙` | `身后为平整素净的冷暗米灰墙面` |
| `背景为 12 点落地窗` | `身后为虚化的深色落地窗帘与极微弱夜色窗外光斑` |
| `主角B在 3:30 面向 9 点质问` | `主角B站居画面右侧三分之一，左侧留出暗部视线空间，躯干微侧向左、三分之二侧脸朝左直盯画外左侧` |

## 二、身体 → 头部 → 视线三层朝向铁锁模板

由于人物定妆图（`CHAR-VID` / `CHAR-FACE`）多为正脸朝向镜头，多模态模型有极强惯性把人物画成“直视镜头摆拍”。凡非打破第四面墙的镜头，必须同时锁死 3 层：
1. **躯干层**：`躯干侧向画面[左/右]侧`；
2. **头部层**：`头部呈[三分之二侧脸/正侧面]朝向画面[左/右/右下方]`（在无首帧多镜连拍中可补注“改变定妆图正脸朝向”）；
3. **视线层**：`双目平视越过画[左/右]边缘紧盯画外[左/右]侧`（或 `垂眼低看面前白瓷碗`），视频中显式加锁 `绝不看向镜头`。

## 三、机位视锥与邻座几何守恒 3 步检查法

1. **拉左右视野射线**：在 360° 平面图从机位位置按焦段张角（`35mm ≈ 54°`、`50mm ≈ 40°`、`85mm ≈ 24°`）画出左右两条视野边线。
2. **盘点视锥内全部实体**：数清左右两条线之间扫到了哪几段桌沿、哪几把餐椅、哪几扇门窗。
3. **逐一处置（零空椅穿帮）**：
   - 扫到在场邻座 → 在该侧按真实左右手方位写明“其左手边延续的桌段旁柔和虚化坐着 `@邻座角色图`”，并把该邻座列入参考图；
   - 不想让邻座入画 → 改为 85mm 紧收景别或把构图右/左边界紧切在主角外侧，确保空椅子落在视锥外；
   - 严禁写“露出四分之一桌角”导致模型误以为桌子在主角身侧断头，把近端座位错画成远端角座。

## 四、复杂多人黑白站位草图规范（3 人以上强推荐）
- 16:9 纯白底黑线极简人物轮廓（只画桌沿、人体朝向轮廓与红色视线/指势箭头，**图内严禁出现任何文字、数字或标签**）；
- 作为最后一张参考图传给 `Seedream 5.5`，正文末尾仅加一句：`严格按最后一张黑白草图的人物站位与红色箭头构图，成图清除所有草图线条与红色标记。`
