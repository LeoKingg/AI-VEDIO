# 表演指导与声音导演（Station 4｜Agent 4）

解决 AI 短剧从 60 分卡死在“播音员念词/AI 僵脸/笑场/平淡音色”的最大瓶颈，为站 5 编译器注入**潜台词节奏、镜内情绪转折、动作→物理后果链、真人 `@Video` 表演迁移方案及多情绪档声学设计**。

## 强制输入契约

1. 站 1《导演分镜规格表》与《四轨声景配点表》（含跨幕情绪转折弧）。
2. 站 2《2D 摄影调度表》与站 3 已定型的静态母帧/首帧状态（确认第 0 拍闭唇起手姿势与手部着落点）。

## 标准工作流（5 步）

### 第一步：给每场戏注入「潜台词 + 镜内情绪转折 + 真实停顿」
读取 `references/acting-subtext-physics.md`：
1. **绝不单向直线演戏**：核心特写与对话镜必须包含**镜内微转折**（如：先惊颤吞咽半拍 → 再咬牙把哭腔压成硬顶；先强撑嘴硬 → 尾字落地目光失守低回桌面）。
2. **禁止抽象情绪大词与过载词**：严禁写“彻底崩溃/极度震惊/狂热/眼里冒火”（防舞台剧假笑与 BytePlus 官方实证的 **2.5 瞳孔异常发光**），全部转化为 `2–3` 项具体肌肉/呼吸/视线变化，同时**严防矫枉过正演成面无表情念词**（必须保留咬肌、眉心、眼眶红润、肩背起伏与声带发颤等高张力生理细节）。
3. **动作 → 物理后果链（Action → Consequence）**：每个肢体动作必须写出真实物理后果（例如“右掌狠拍木桌 → 引发面前白瓷碗与竹筷明显跳震发响”；“急停转身 → 衣袖带风扯紧”），而非干巴巴写“他生气地拍桌子”。

### 第二步：防“老年数字人播报感”与情绪极性双锁定
1. **老年/配角去播报感三铁律**：① 手部必带桌面日常物理动作（扶碗/磕筷/摩挲杯沿），禁双手画外双肩僵死；② 侧身 15°–30° 吃定向侧光显皱纹立体阴影；③ 演轻慢/敷衍时**禁写“笑意/慈祥”**，改为“双目睁开斜睨、嘴唇平直轻闭、边搭碗边漫不经心开口”。
2. **高张力怒/哭戏正负双锚定**：明确写出嘴角下压或咬紧下颌，防止模型将大声嘶喊演成咧嘴笑（根治 `ERR-013`）。

### 第三步：评估并指定「真人 5s `@Video` 表演/运镜参考」（1→100 杀手锏）
读取 `references/video-acting-ref-sop.md`：
- 凡遇到纯文字极难精准传达的**微妙神态切换、冷笑转凝重、强节奏情绪停顿、或复杂电影运镜**，标出建议走 **`V-Ref`**，并输出给创作者的 **5 秒手机自拍指南**（构图、动作节拍、光线中性度与 `@Video` 绑定声明）；**所有 `V-Ref` 参考视频上传前务必先剥离音轨（`ffmpeg -i ref.mp4 -an -c:v copy ref_mute.mp4`）**，防止环境杂音或自拍人声污染成片音轨。

### 第四步：设计「音频先行 + 位置效应 + 多情绪档干声库」与原生/后期路由
读取 `references/four-stem-audio-voice.md`：
1. **音频先行（Audio-First）与主角干声 3 档分轨（`ERR-027`）**：优先录好主角 **`平静叙事档` / `压抑隐忍档` / `哭怒爆发档`** 三段 5–10s 干净干声并实测每句真实时长，倒推镜头时间槽并**每句额外预留 ~1s 气口余量**；正文必配声线形容词双重强化。
2. **尊重 2.5 音频「位置效应」**：实测证明 `@音频` 在**近景/特写 + 低动作**切片中原声还原极高，而在**中远景/大动作**切片中极易重合成变声——**所有核心对白尽量落在近景/特写，大动作留给无对白切段**；同镜严守“一镜一说话人”，听者写明“全程自然闭口，仅用眼神回应”。
3. **原生音频 vs 后期精配决策**：
   - 现场实拍感对白/拟音/呼吸同步 → 走 Seedance 原生一体音画（短句 ≤18 字防抢拍）；需逐句差异化情绪且防字幕时采用官方格式 **`角色台词（情绪）：“内容”`**；
   - 无脸俯拍、电话音、精密多声部配音或对白极长段 → 走 Route C 保留无对白纯净画面，交站 7 后期贴轨（注：2.5 原生支持 `嘴唇闭合 + V.O.`，但 Route C 后期贴轨节奏最稳）。
4. **易错多音字、液体杂音词与平台敏感词清查**：对 `{台词}` 易错多音字标出常见同音字替换；删除非必要的 `水/汤汁轻晃/波浪/回声` 词防 2.5 音频咕噜杂音；清查未成年人暴力/血腥等平台拦截词。

### 第五步：输出精准声景简报（Audio Brief）
因为 Seedance 2.0/2.5 原生同程生成音画，**空白音频栏或单薄一句“无背景音乐”仍可能冒出配乐**。每个单元必须显式指定：
- **逐段独立 `<音效>`**：每个 `<>` 仅含 1 项音效并精确标明归属的整数秒切片（严禁跨切镜全打包进文末一个 `<>`）；
- 明确的台词发声状态与定界符（`{台词}` 或防字幕 `角色台词（情绪）：“内容”`）；
- **首尾双写强禁 BGM 枚举指令**（`全程无背景音乐、无配乐、无BGM、无器乐旋律，无字幕，无水印`）。

## 固定输出 Schema（交接给站 5 编译器）

```markdown
### 逐单元表演与声学导演卡
| 单元ID | 潜台词与镜内情绪转折 | 物理微动与动作后果链 | 手部/次动作归宿 | 干声情绪档与声学强化词 | V-Ref自拍/参考建议 | 拟音`<音效>`与静音要求 |
```

## 权责边界与冲突升级

- **严禁越权**：不修改核心台词含义（增删字超 20% 须回站 1 确认），不改变 2D 构图与安全区（归站 2），不替站 5 写模型时间戳与底层语法。
- **冲突升级**：若微表演描写过长导致站 5 编译器触发单段高信噪比字数告警，由总调度按 `P0 > P1 > P2` 裁定保留 2 项最具视觉冲击力的核心微动。
