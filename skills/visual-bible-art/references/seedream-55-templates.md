# 即梦 Seedream 5.5 资产与 S 级剧照首帧 Prompt 模板库（官方 5 段式精简版）

> **核心规范（对齐 ByteDance Seedream 5.5 官方指南）**：
> 1. **130–220 字高信噪比 5 段式**：`① 图像类型与画幅 → ② 参考图显式分工 → ③ 主体与 3 个硬锚点 + 唯一动作视线 → ④ 真实光源方向 + 镜头焦段 + 哑光毛孔质感 → ⑤ 保留/修改清单（编辑时）`；
> 2. **多图必分工**：写明每张参考图各自提供什么，绝不笼统写“延续 A 和 B”；
> 3. **先 1.5K 试构图，再 2K 定稿；70% 对了就转同图局部精修**（每轮改 1 点 + 保留清单，不用推倒重抽）；
> 4. **用正向质感词替代否定词堆砌**（写“可见皮肤毛孔、哑光无蜡质感、自然阴影”）。
