# 平台分发与安全区预设：原生 9:16 全屏竖屏短剧（`platform_vertical_916`）

> **适用范围**：红果短剧、抖音/快手/TikTok 原生竖屏微短剧、强节奏情绪爽剧与信息流投流短片。

## 1. 画幅与导出规格
- **生成母版**：全链路原生 `9:16`（`1080×1920`），`24fps` 或 `30fps` 全片统一。
- **防自动乱字幕提醒**：BytePlus 官方实测 `9:16` 竖屏自发冒出乱码字幕的概率高于 `16:9`，因此除尾句强约束 `无字幕，无水印，画面中绝不出现任何文字` 外，参考图亦须 100% 无任何文字。

## 2. 竖屏 UI 安全区硬规范（Station 2 摄影必检）
```text
┌───────────────────────────┐  9:16 全屏画布 (1080×1920)
│   [顶部避让区：上 14%]     │  不放主角眼睛或关键顶部道具
├───────────────────┬───────┤
│                   │ 右侧  │  · 右侧 16% 避让区：抖音/TikTok 点赞头像收藏栏
│   核心表演安全区   │ 16%   │    禁止把关键对峙人物的脸贴死在右边界！
│  (左84% × 中56%)  │ UI栏  │  · 人物近景头部宜居画面上 1/3 至正中偏左
│                   │ 避让  │
├───────────────────┴───────┤
│   [字幕区：下 20%–30%]    │  对白字幕固定居此区，避免遮挡人物胸口以上表演
│   [底部避让区：下 20%]     │  账号名/进度条/广告挂件，核心手部道具不得落此区
└───────────────────────────┘
```

## 3. 竖屏镜头语言微调
- 竖屏天然不利于 4+ 人横排同框，多人群戏必须用**前景虚化肩背 + 纵深前后排布（Z 轴分层）**替代横排一字长蛇阵；
- 近景/特写人脸占比极具冲击力，每 `6–10s` 必切一次景别或听者特写，维持高频多巴胺节奏。
