# 题材美学预设：高张力悬疑 / 犯罪 / 心理惊悚（`genre_suspense_thriller`）

> **适用范围**：悬疑反转、密室博弈、都市罪案、心理惊悚与强节奏爽感短剧。

## 1. 摄影机与光学签名
- **机身与镜头锚**：`ARRI Alexa 35 / RED V-Raptor 实拍电影质感`、`24mm 广角畸变压迫 + 50mm 锐利中景 + 100mm 长焦偷窥压缩`、`冷峻硬边高反差布光`、`轻微镜头光晕（halation）`
- **材质与氛围锚**：`雨湿反光路面/金属冷反光/老旧荧光灯频闪感`、`细微高感暗部胶片颗粒`、`真实冷汗微光与紧绷面部骨相`、`哑光写实无网游CG感`
- **绝对禁词**：`8K`、`赛博朋克霓虹乱光`、`奇幻发光瞳孔`、`动漫特效光波`

## 2. 核心光影色彩配方
| 情绪场次 | 主光源与光比 | 阴影偏色 / 高光色温 | 暗部占比 |
| :--- | :--- | :--- | :---: |
| **暗夜潜伏 / 调查** | 单点手电筒/街灯/车灯强切硬光，大面积不可见深影 | 深墨蓝/冷绿阴影 + 刺眼冷白或钠灯枯黄高光 | ≥ 65% |
| **密室审讯 / 心理博弈** | 顶光垂直压暗眼窝或单侧百叶窗条纹硬光 | 低饱和冷灰青 + 极窄高对比锐利亮边 | ≥ 60% |
| **真相揭露反转** | 突然开启的主灯/开门涌入的强逆光打破暗场 | 由冷青骤然切入刺眼冷白或警示红光点缀 | 瞬间对比翻转 |

## 3. 节奏与声景基调
- **节奏**：每 `8–12s` 必埋一个视觉线索或认知反转；高频使用 `SEQ-Multi` 快切（3–4 切/12s）、微荷兰角（`5°–8°`）、焦点转移（Rack Focus，前景凶器/证据移焦至后景人物神色）。
- **声景**：低频环境嗡鸣（空调/冰箱/雨声/电流声）持续铺底，关键线索入画配极轻低频冲击音（Sub-bass Hit），反转瞬间前强制 `0.3–0.5s` 彻底静音。
