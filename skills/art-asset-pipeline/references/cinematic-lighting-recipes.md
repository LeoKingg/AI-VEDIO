# 摄影师思考前置法与光照-皮肤物理交互指南

## 一、摄影师思考三问（动笔生图前必过）
1. **拍 Moment，不拍 Object**：不要写“她站在厨房门口”，改写“她刚停步、手指搭在门框边缘两厘米处”。**爆发前半秒的蓄势（Anticipation）永远比大张嘴做满更有张力，且第 0 拍闭唇态最利于视频释放自然演技**。
2. **克制留白（30%–50% 负空间）**：把非核心墙角压入深暗阴影，颜色来自真实实用光源与空气纵深，绝不往屋里硬塞杂乱装饰。
3. **视线指向（严禁看镜头）**：除刻意打破第四面墙外，静帧与视频人物视线必须落向对手、手中物件或画外，看镜头 = 廉价影楼自拍。

## 二、光照-皮肤物理交互公式（消除“抠图贴片感”）
每张实景母帧与含人视频必须交代环境实用光源如何落在皮肤与衣物上：
`[实用光源位置/色温] 照亮 [人物具体受光面] + [阴影自然落点] + [环境微反光]`

- **室内夜戏吊灯**：`上方低照度暖黄吊灯照亮额头、鼻梁与颧骨，眉骨在眼窝投下自然阴影，背光半颊沉入冷灰暗部，木桌微弱反光映在下颌。`
- **玄关冷青对峙**：`头顶低照度冷青吸顶光勾亮发顶与肩线，侧脸半面受冷青光照亮、另一半滑入深灰阴影，前景边缘渗入极弱暖黄室内余光。`
- **阴天室内/车内日戏**：`单侧旧窗透入的阴天冷白漫射光铺亮近窗半颊与衣领，背光侧平滑过渡入柔和冷灰阴影。`
- **清晨侧逆光外景**：`低角度金色朝阳从斜后方切入勾亮碎发与肩线轮廓，正脸由清晨天空冷蓝漫射光自然承托。`

## 三、克制环境微动态库（视频阶段每单元精选 2–3 项）
- **室内夜戏**：饭菜极淡热气缓缓升起、吊灯光在瓷碗/杯沿轻闪、窗外深暗夜色掠过微弱远车光斑、呼吸带动微弱衣领起伏。
- **过道/车厢/户外**：发丝微动、空气细微尘粒在顶光束下浮游、衣袖受力自然褶皱、玻璃雨滴滑落或微弱倒影流动。
