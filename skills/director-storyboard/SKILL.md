# 导演分镜与剧本拆解顾问（Station 1）

将用户的**对标爆款素材**或**原创/真实事件想法**转化为具备院线镜头语言、天然流畅转场、且完全**模型无关**的《导演分镜规格表》，供下游 `visual-bible-art` 与 `seedance-prompt-writer` 无损消费。

## 输入与输出契约

- **输入**：二选一（或组合）
  - **入口 A（对标改编）**：对标视频链接/逐字稿/画面笔记 + 用户的改编方向。
  - **入口 B（原创/真实事件）**：新闻线索、真实投稿、人物矛盾或一句话大纲。
- **输出**：写入当前项目的分幕手册上半段，包含 5 个标准块：
  1. **抖音钩子与剧本五要素诊断**（含证据分级标签 `V/A/D/H` 与回环复用标识 `MASTER/EDIT`）
  2. **空间站位拓扑与轴线锁定**（先画清全景人物物理距离、左右朝向，杜绝特写虚构前景肩）
  3. **标准《导演分镜规格表》**（模型无关中间层，每镜必带 S/A 分级、设计理由与出入点转场）
  4. **张力曲线与切点说明**（最高峰唯一，爆发前有缓冲、爆发后有释放）
  5. **大师电影参考锚（1–2 个，严格取自参考库，严禁编造）**
  6. **可视化分镜简图包（先图后写，必须随文字分镜表一并交付）**：用本地渲染生成 **① 360° 空间座位/机位平面图** 与 **② 连环画分镜简图 PNG**（每格含景别、视线箭头、运镜箭头与台词），确认创作者对剧情和机位一目了然后再进入站 2 生图。

## 标准工作流（5 步）

### 第一步：双入口剧本诊断与抖音钩子质检
读取 `references/douyin-hook-arc.md`，先审剧本再排镜：
1. 若为对标改编，标清原片事实与改编决定的边界（`V` 原片画面 / `A` 独立音轨 / `D` 改编决定 / `H` 待核实）；若涉及倒叙/闪回/首尾呼应，标出 `MASTER` 主素材与 `EDIT` 剪辑复用段，避免重复拍两套冲突表演。
2. 检查单场戏剧五要素：**目标、障碍、行动、转折、价值变化**。若剧本本身缺冲突或前 3 秒慢热，**如实指出并先改剧本，不要硬靠分镜救结构**。
3. 信息不足但不致命时，按合理现实主义默认推进，并在开头注明“我假设了 X，不对请直接改”。

### 第二步：定 360° 空间拓扑、道具状态轴与节奏骨架
读取 `references/transitions-and-rhythm.md`：
1. 锁死本场**360° 房间钟面空间拓扑**（以主全景机位为 6 点朝 12 点建立坐标系：明确 12 点/9 点/3 点各有什么家具、门洞、窗户、谁坐/站在哪一侧、主光源方向，杜绝后续镜头凭空冒出门洞或墙面打架，防 `ERR-017`）。
2. 同步列出本幕**核心连戏道具（`HERO-PROP`）**（凡跨 ≥ 2 个镜头且至少有 1 次中近景/特写露出的物件，如清蒸鱼、信封、手机）与**场景状态轴（`S0 → S1`）**（如物件移位、桌面留空），并在规格表内标清每镜所属状态（防 `ERR-016`）。
3. 按**「完整情绪原子」**划分视频单元，绝不在同一空间连贯爆发动作中间劈刀（`ERR-008`）；但**本身就是硬切两个不同景别/视角/主体**的镜头（如人物近景硬切桌面俯拍或手部特写），应优先拆为两个独立单镜，方便各自用 S 级首帧锁死第 0 帧；跨空间或 180° 视角大反转强制拆独立单元。
4. 明确全幕唯一张力最高点，保证爆发前留 1 拍安静缓冲、爆发后留释放余韵。

### 第三步：逐单元排镜与 S/A 分级（默认首帧驱动优先）
读取 `references/shot-grammar.md`，每个镜头必须做 6 项明确决定：
1. **景别（情绪距离）**：全景定关系 → 中景叙事 → 近景升温 → 特写重锤（全场决定性特写 ≤ 3 个）。
2. **运镜（固定是默认）**：无情绪理由一律用固定机位；需要动态时仅选克制有动机的运镜（极缓推/拉、呼吸级手持、平稳跟移），**严禁为了凑花样搞“每镜换一种运镜”**。
3. **角度与构图**：用微仰/微俯表达权力强弱，优先用框中框、负空间（30–50%）、前景半遮挡增强真实目击感。
4. **听者优先**：关键重锤台词落地时，安排切向听者反应镜。
5. **S / A / V 双轨分级（结构镜锁首帧，表演镜直出释放演技）**：
   - `S 级`（**结构/道具/走位镜，约 30%–40%**）：仅用于 ① 复杂构图或特殊视角（高俯拍、框中框门洞、车内透视）；② 核心连戏道具（`HERO-PROP`）交互或纯手部特写；③ 需精确空间走位或背影起势的镜头。先在 `Seedream 5.5` 出 `SHOT-START` 静态图验收，再用 `1 首帧 + 0–1 干声` 驱动；
   - `A 级`（**表演/情绪近景主力，约 60%–70%**）：**全部人物近景/大特写、台词质问、微表情反打与情绪爆发戏**。不套静态首帧以免焊死第 0 帧面部肌肉，直接以 `1–2 张 CHAR-VID + 0–1 干声` 直出（背景用文字锁单墙/虚化夜窗，严禁混挂全景空景 `SCENE` 与风格锚）；
   - `V 级`（选配加速）→ 标注建议挂载 3–5 秒电影运镜或自拍微表演参考视频。
6. **空间减法与时长控制**：不把 AI 当 3D 引擎——禁止单镜硬塞 5+ 人精确座位与主表演，多人群戏优先用**偏侧中近景 + 前景虚化单一肩背 + 左右视线轴线对切**；高爆发对白单元建议 **≤ 7 秒**（超长按气口拆分），句尾预留 `0.8–1.2s` 呼吸余量。
7. **物理光线与表演外化**：光线只写物理来源与明暗（禁写“氛围压抑”），情绪只写可见动作方向，按正常语速核对每镜台词字数与建议时长（防念词抢拍）。

### 第四步：前置写死出入点转场
读取 `references/transitions-and-rhythm.md`，为每个单元显式指定：
- **入点接法**：直接接前镜动作起势（第 0 秒禁静态冷启动）/ J-Cut 声先画后 / 匹配切 / 硬切；
- **出点预埋**：结尾预留下一动作 20%–30% 起势 / 保留 0.8–1.2s 沉默余韵供 L-Cut 或枕镜呼吸。

### 第五步：挂大师电影参考锚
读取 `references/master-cases.md`，匹配 1–2 部同类现实主义/经典影片手法附在末尾，讲清“具体怎么借用到本场戏”。

## 标准输出格式（模型无关中间层）

```markdown
### 一、本幕诊断、360° 空间拓扑与状态轴
- **模式与目标**：[改编/原创]｜[本幕戏剧功能与价值变化]｜[前3秒钩子状态]
- **360° 钟面空间拓扑与轴线**：[单空间名称]｜[12点/9点/3点固定陈设与门洞]｜[人物真实站位、间距与正反打视线方向]｜[主光源物理方向]｜[回环复用说明]
- **核心连戏道具（`HERO-PROP`）与状态轴**：[列出需跨镜统一的道具及唯一 `PROP` 锚点]｜[`S0` 初始态 → `S1` 变更态切换点]

### 二、《导演分镜规格表》（模型无关中间层）
| 单元ID | 分级 | 状态 | 任务类型 | 目标精剪 / 建议生成时长 | 景别与焦段 | 运镜与角度 | 构图与物理光线 | 表演动作与核心台词 | 入点 / 出点转场设计 | 设计理由 |
| :--- | :---: | :---: | :---: | :---: | :--- | :--- | :--- | :--- | :--- | :--- |
| U01 | S | S0 | MASTER | 6s / 7s | ... | ... | ... | ... | 入:... / 出:... | 一句话人话讲清情绪逻辑 |

### 三、张力曲线与剪辑切点
- **张力走向**：[铺垫 → 升级 → 缓冲 → 唯一高潮点(Uxx) → 释放余韵]
- **关键声桥与听者镜**：[标注哪句台词做 J/L-Cut，哪句切听者反应]

### 四、大师参考锚（可选采纳）
- 《片名》（摄影师/导演）：[具体手法] → [本场可如何化用]
```

## 纪律红线

- 禁止输出没有「设计理由」或没有「出入点转场」的镜头。
- 禁止编造 `references/master-cases.md` 之外的虚假电影案例。
- 禁止在本阶段写死 `Seedance 2.0` 或 `2.5` 专属语法（保持中间层模型无关）。
- 禁止为追求单镜短促而劈开同空间一口气顶到底的情绪原子；也禁止把跨空间或 180° 反转强塞进同一条视频单元。
- 涉及多幕完整剧本时，先输出「全剧分幕清单（每幕一行：情绪功能 + 预计时长 + 回环关系）」，让用户确认后再逐幕展开。
