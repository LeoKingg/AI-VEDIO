# AI-VEDIO V3.0 工业级短剧制片总纲 SOP

> **版本**：V3.0（**Seedance 2.5 主力 + 2.0 完整兼容**｜1 → 100 院线质感与爆款留存工业管线）  
> **定位**：端到端 6 阶段制片总图与 5 模生成路由总控表。总调度宪法见 `docs/STUDIO_CONSTITUTION.md`，各工位细则单一维护于 `skills/` 下对应专职 Skill。

## 一、V3.0 核心范式跃迁：从「逐镜手搓」到「场次序列优先 · 5 模路由」

V3.0 彻底摒弃“把一场 40 秒戏硬拆成 11 个孤立 4s 单镜再硬拼”的低效割裂打法，充分利用 **Seedance 2.5（主力：`4–30s`、整数秒时间戳、多格线稿分镜/多关键帧、`MOV` 无损编辑延长、单镜多机位重拍、480p 草稿流）** 与 **Seedance 2.0（兼容：`4–15s`、镜号制多镜头连拍）** 的原生导演能力，按戏份性质自动路由至 5 种生成模式：

| 模式代号 | 定位与适用场景 | 核心资产与语法要点 | 2.5（主力） / 2.0（兼容）甜区 |
| :--- | :--- | :--- | :--- |
| **`SEQ-Multi`**<br>原生多镜头连拍 | **同空间对话正反打、情绪阶梯递进主力**（把 2–4 个同房间关联切镜合并进 1 次推理，天然 100% 同光同色同底噪） | 1 张实景空间/开场首帧 + 1–2 人双锚（按首出场顺序上传）+ 匹配情绪干声；`2.5` 用连续整数秒 `[0s-4s]`，`2.0` 用 `镜头1/2/3` | `2.5`：`10–25s`（2–5 切）<br>`2.0`：`8–15s`（2–3 切） |
| **`SEQ-Grid`**<br>线稿/多关键帧直驱 | **需要强控构图变化的多镜头剧情段、蒙太奇或连环动作推进** | ① 概念驱动：1 张 `≤15` 格无文字黑白线稿分镜 + 场景 + 人物；<br>② 像素级严格对齐：按序上传多张独立关键帧，首句写 `按顺序将@图1至@图N作为关键帧` | `2.5`：`10–30s`（原生强项）<br>`2.0`：`8–15s`（多图关键帧） |
| **`M-Master`**<br>闭唇实景母帧复用 | **高频跨镜/跨幕特写机位、情绪重锤独白、跨幕泪痕/妆容精控**（彻底废除外来风格图进视频） | 基于本场真实空景预烘焙第 0 拍闭唇实景母帧（`≤255` 字）+ `@角色设定卡`（提取右半幅大头五官）+ 情绪档干声；可叠加已过审锚点 `@Video` 锁影调 | `2.5` / `2.0`：`4–12s` |
| **`V-Ref`**<br>参考视频/白模驱动 | **1→100 电影质感跃迁武器**：高难运镜（环绕/希区柯克/跟拍）、真实呼吸停顿与细腻微表演迁移 | 人物/实景图 + **3–10s 参考视频**（电影运镜片段 / 5s 手机自拍微表演 / 粗颗粒 3D 白模），显式声明 `@视频1 仅参考运镜/表演节奏` | `2.5`：`5–20s`（支持白模+多参考）<br>`2.0`：`5–15s` |
| **`S-Struct` / `E-Edit`**<br>结构单镜 & 原生编辑/重拍 | ① 4+ 人精确满座几何、高俯拍、核心连戏道具交互；<br>② 成片局部去穿帮/改台词/补尾帧，或 **2.5 单镜表演多机位重拍** | `S-Struct`：精准首帧或首尾帧；<br>`E-Edit`：直接指代 `@视频1`（不写“参考”）执行增删改/延长/多机位重拍，**输出 `MOV`** 锁色温 | `2.5`：单镜 `4–10s`；重拍/编辑 `≤20s`（先 `480p` 测再 `1080p`）<br>`2.0`：单镜 `4–8s` / 局部编辑 |

> **跨版本防漂移铁律（BytePlus 2026-11 官方实证）**：`Seedance 2.5` 与 `2.0` 存在明显审美色温差异，**同一场戏严禁混用 2.0 与 2.5 独立生成片段**；若必须以 2.0 成片续接 2.5，须以 2.0 视频为输入走 2.5 延长并输出 `MOV`。

## 二、6 阶段闭环工业流水线

### Stage 0｜立项、预设加载与 Step 0.5 剧情拍板
1. 运行 `python3 scripts/init_project.py --name <项目名> --genre <题材预设> --platform <平台预设> --model 2.5` 初始化项目脚手架与 `manifest.json`。
2. 编写 **Step 0.5《剧情与改编讨论分镜表》**（纯文字聊透冲突、台词、留存钩子与反转，先不画图、不写 Prompt），经创作者拍板后锁定剧本，杜绝后期大改返工。

### Stage 1｜导演分镜、5 模路由与四轨声景设计（`director-showrunner`）
1. 通过商业与 1→100 剧本门禁：**前 3 秒视听双钩 + 每 12–15 秒信息/情绪转折 + ≥30% 视觉潜台词（Show Don't Tell）+ 听者反应镜配比**。
2. 第 `N≥2` 幕强制先读第 `N-1` 幕末镜原文，填完 **Cross-Act 4 维交接卡**（妆容泪痕汗渍 / 情绪心理转折 / 站坐姿态 / 道具状态）。
3. 产出《导演分镜规格表》（显式标注 **5 模路由**、状态轴 `S0→S1` 成对守恒 `Origin - / Destination +`、出入点转场与相邻防跳剪）及《四轨声景配点表》（Dialogue / Room Tone / Foley / Score 与高潮前 `0.5s` 抽空静音）。

### Stage 2｜空间几何、视觉圣经与 Pre-Vis 动态预演（`cinematography-blocking` + `art-asset-pipeline`）
1. **双层坐标隔离**：导演层锁死 360° 房间拓扑、视锥邻座守恒（扫到的在场邻座要么虚化坐实，要么用焦段裁出画外）与 **16:9 / 9:16 字幕与 UI 安全区**；输出给模型层时 100% 翻译为 **2D 画面空间四要素 + 身体/头部/视线三层锁**（零钟面词）。
2. **SSOT 静态资产烘焙（`Seedream 5.5` 同账号闭环，守住 30 天写实人脸免风控窗口）**：
   - 按 `presets/` 定《视觉圣经》，**1 人严格 1 张 `#555A64` 侧光 `CHAR-SHEET` 复合角色设定卡**（左正面全身+右 50%+ 高清大头，彻底淘汰三视图→单人图→纯头三连跳）+ `PROP` + 单空间纯净 `SCENE`（及成对局部编辑的 `SCENE-S1`）；
   - 按路由表生产 `SHOT-MASTER` 闭唇实景母帧、`S-Struct` 首帧或无字黑白线稿分镜（全部遵循 `≤255` 字极简正向、零视觉否定词、人物在前原则）；
   - **严禁将外来 `STYLE-REF` 风格锚带入任何视频任务**。
3. **Pre-Vis 零成本动态预演（Animatic）**：将验收后的关键帧/线稿草图 + 粗配音/临时音效拉进剪映粗排一遍，验证前 3 秒冲击力、台词读速与切点，**0 视频积分提前排除节奏硬伤**。

### Stage 3｜表演声学精雕与双引擎编译（`performance-sound-director` + `seedance-compiler`）
1. **活人级演技与多情绪干声**：为主角建 **平静 / 压抑 / 爆发 3 档干声库**；为每个单元写入潜台词、镜内情绪转折、动作→物理后果链（Action→Consequence）；对高难微妙神态或复杂电影运镜，拍摄 5s 手机自拍或挂载电影参考片段走 `V-Ref`。
2. **任务分配型纯净编译（Job Assignment）**：遵循“**文字管语义（谁干什么+物理后果+声景），参考管标准（长相/光影/运镜/节拍）**”，按 `2.5`（默认）或 `2.0` 适配器输出纯净 Prompt，严格采用官方分隔符 `{台词}`、`<音效>`、`(音乐)`、`【字幕】`，按首出场顺序显式绑定素材与主体唯一标签。

### Stage 4｜双保险盲审门禁与工作台自动编译（`redline-auditor`）
1. **机械确定性扫描（生图 + 视频 + 跨文件 Manifest 三合一）**：
   ```bash
   python3 skills/redline-auditor/scripts/lint_prompt.py \
     --model 2.5 \
     --manifest projects/<项目名>/manifest.json \
     --file projects/<项目名>/03_act01_handbook.md
   ```
   必须达到 `P0=0` 方可进入语义盲审。
2. **上下文隔离语义盲审**：独立子 Agent 只读目标手册、上一幕末镜原文、`manifest.json` 与 `redline-checklist-v3.md`，只报 `PASS / FAIL`，绝不擅改文风。
3. **一键编译零失步 HTML 工作台**：过审后执行 `python3 scripts/build_workbench.py --handbook <手册路径> --output <工作台HTML>`，自动生成一键复制与锚点过滤工作台，彻底消除人工维护多份副本的失步风险。

### Stage 5｜分批实测、7 维质检医生与院线抛光交付（`post-qa-finishing`）
1. **分批锚点实测**：先跑 3–4 个锚点镜（`2.5` 复杂序列先跑 `480p` 草稿测再切 `1080p`），遵守总调度《两击止损红线》，命名归档 `[单元ID]_v[N]_[PASS|FAIL].mov/.mp4`。
2. **7 维成片量化质检 + 4 级低成本修片决策树**：
   `① 剪映零成本急救（裁切/镜像/调音） → ② Seedance 2.5 原生局部编辑/延长/多机位重拍（MOV 输出） → ③ Seedream 5.5 单轮微调首帧重跑 → ④ 迭代医生单变量改词重抽`。
3. **院线级后期抛光（70 分 → 95 分）**：逐镜曝光/肤色匹配 → 4 轨混音（Room Tone 铺底 + J/L-Cut + 高潮前 `0.5s` 静音 + `-14 LUFS`）→ AI 超分/去蜡质/去闪烁 → 统一 24fps 电影帧率 + 10–15% 35mm 颗粒 → 导出 16:9 原生母版 + 平台包装版；新规律与错题回写 `docs/ERROR_PLAYBOOK.md`。
