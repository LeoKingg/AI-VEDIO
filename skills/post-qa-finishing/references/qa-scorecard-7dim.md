# 成片 7 维量化质检评分卡（QA Scorecard）

收到即梦生成的每一张关键图或每一条视频，按以下 7 维客观打分（拒绝笼统说“还行”或“不对劲”）：

| 维度 | 合格红线（`PASS`） | 一票否决项（必须处置） | 优先处置级 |
| :--- | :--- | :--- | :---: |
| **1. 角色与服化一致** | 骨相、发型、年龄感、配饰与衣袖配色与 `manifest.json` 锚点吻合 | 变脸、串色（如深炭灰变浅蓝）、多人双胞胎分身、多出手指 | `L2` 编辑 / `L3` 修图 |
| **2. 空间与道具连戏** | 视线轴线正确、可见座位 100% 坐实、`S0/S1` 道具守恒、无隔壁杂物 | 冒出空椅、冒出冰箱/灶台、桌面长回已移除物体（粉红大象）、越轴 | 无字越轴 `L1` 镜像；穿帮杂物 `L2` 原生擦除 |
| **3. 光影与画风统一** | 与本场锚点片色温、明暗对比、墙面质感一致 | 明显像换了剧组（外景光/棚拍平光侵入暗调夜戏） | 微差 `L1` 逐镜调色；剧变 `L3` 换实景母帧 |
| **4. 表演与情绪极性** | 呼吸停顿自然、手部物理接触可信、情绪与台词一致 | 僵硬站桩冻手、怒/哭演成咧嘴笑、老年磨皮蜡像、2.5 瞳孔发光 | `L4` 改微动 / 切 `V-Ref` 5s 自拍参考 |
| **5. 运镜与物理帧质** | 运镜顺滑有动机、刚体直线不弯曲、无高频闪烁 | 鬼影叠化、车窗/桌沿融化变形、双运镜剧烈抖屏 | `L4` 降为单一运镜 / 改用 `S-Struct` |
| **6. 声画与口型同步** | `{台词}` 吐字清晰准确、嘴型对得上、无莫名广告配乐 | 吞字错读、长句后半口型漂移、强行加了廉价 BGM | 尾音咔哒 `L1` 淡出；错读 `L2` 改音频或同音字重跑 |
| **7. 剪辑余量与安全区** | 首尾留白可切、主角双眼与证物落在安全区 | 尾字被截断无余韵、关键表演压在抖音点赞栏/字幕区 | 轻微边缘瑕疵 `L1` 放大裁切；重度遮挡 `L3` 调构图 |

## 总体放行裁决标准
- **直接放行（`PASS`）**：7 项全绿；
- **条件放行（`PASS-L1`）**：仅含 `L1` 可 1 分钟救活的轻微瑕疵（如微裁 `105%`、水平镜像、微调色温），记录参数至 `04_post_jianying_memo.md` 后直接放行，**严禁重抽高演技画面**；
- **拦截修片（`FAIL`）**：存在任意结构性/身份/演技硬伤，按 `references/rescue-decision-tree.md` 进入 `L2 / L3 / L4`。
