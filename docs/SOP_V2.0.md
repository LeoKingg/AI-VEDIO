# AI 视听制片全流程总纲 SOP（V2.0）

> **版本**：V2.0（面向抖音 16:9 电影感现实主义剧情短片）  
> **定位**：通用制片流程单一事实来源（SSOT），与具体 AI 模型语法解耦；模型专属语法统一维护在 `skills/seedance-prompt-writer/references/`。

---

## 一、目标规格与生产边界

| 项目 | 锁定规格 |
| :--- | :--- |
| **分发平台与画幅** | 抖音情感剧情中视频；**16:9 横屏主体**（抖音 9:16 竖屏封装时上下留电影黑边，上黑边放吸睛钩子标题，下黑边放电影双行/单行字幕） |
| **单集时长与节奏** | **1.5–3 分钟**；**3–5 天精品周更**（质量、完播率与账号 IP 心智优先，绝不靠粗制滥造堆量） |
| **主攻题材** | **中国当代现实主义真人剧情短片**（预留题材插件扩展位，通用影视语法保持题材无关） |
| **主力工具链** | 编剧/分镜/Prompt/门禁：本仓库 4 大 Skills → 生图：**即梦 `Seedream 5.5`（或 `5.0 Pro`）单平台闭环** → 生视频：**即梦 `Seedance 2.0 / 2.5` 双适配** → 后期：**剪映专业版** |

## 二、5 步闭环生产流水线

彻底废除两类极端反模式：① **重资产空转**（开机前一次性画完 50+ 张图再拍）；② **纯靠文字硬扛电影感**（拿纯白棚拍人像 + 亮堂空景硬拼视频，期望靠 5000 字 Prompt 救场）。

### 第 1 步：双入口剧本定稿与抖音钩子质检（站 1：`director-storyboard`）
1. **双入口兼容**：
   - **入口 A（对标爆款改编）**：拆解原片情绪弧线、时长节拍尺与反转结构，严格标注证据分级标签（`V` 原片画面 / `A` 独立音轨 / `D` 改编决定 / `H` 待核实 / `T` 实测结论），完成本土化/新视角重构与**非相邻回环核验**（区分 `MASTER` 主素材与 `EDIT` 纯剪辑复用）。
   - **入口 B（原创/真实事件编剧）**：从新闻线索、真实投稿或一句话核心冲突展开，构建「前 3 秒情绪核弹冷开场 → 现实障碍递进 → 关系转折 → 情绪宣泄高潮 → 尾板金句留白」结构。
2. **强制过审 3 项商业门禁**：
   - 前 3 秒内是否出现**视觉冲突 + 听觉钩子**（拒绝慢热空镜铺垫）；
   - 每幕是否具备完整戏剧五要素（目标、障碍、行动、转折、价值变化）；
   - 全剧情绪高潮是否唯一，且爆发前有静默缓冲、爆发后有释放余韵。
3. **先交“可视化分镜包”再进生图（刚性交付门槛）**：拆解剧本并写完《导演分镜规格表》后，必须同步生成并交付 **① 360° 空间座位/机位平面图** 与 **② 连环画分镜简图（含每格景别、人物朝向、运镜箭头与核心台词）**，让创作者 30 秒看清整场剧情流后再启动生图。

### 第 2 步：全片视觉圣经与核心底座锁定（站 2：`visual-bible-art`）
执行经过实战验证的**「稳定性优先：核心底座一次锁死 + 核心道具与状态溯源 + 每镜首帧先行」**（原则：**1 次视频返工成本 ≈ 10+ 张图片，绝不为了省几张底图而让视频抽卡盲赌**）：
1. **先立《视觉圣经》（`01_visual_bible.md`）**：在画第一张图之前，确定全片色彩签名（室内/室外冷暖分区）、光比与暗部压黑比例、摄影机与镜头焦段锚（如 ARRI Alexa + 35mm/85mm + 细微胶片颗粒），并选定/生成 **1–2 张全片「色彩与光影参考图（`STYLE-REF`）」**（主要用于生图阶段烘焙光影，已绑定空景或首帧的视频单元不再重复挂载）。
2. **核心底座资产（单一真相源，上游派生下游）**：
   - **身份母档（`CHAR-BASE`）**：`Seedream 5.5` 16:9 纯净三视图，**仅用于 `Seedream 5.5` 生图派生（换装、背影/侧脸首帧合成、局部精修），绝不直接喂给视频任务**。凡后续幕次有正脸重要戏份的角色，哪怕第一幕只露背影或远景，也在首次入画前先定型，避免下游倒逼上游。
   - **进视频/生首帧专用单人图（`CHAR-VID`）**：由母档派生（轻量配角可直接单步生成），采用**中深灰底（`#555A64`）+ 45° 定向侧光（无平光填充）**，彻底消除纯白 `#FFFFFF` 底洗灰暗调电影光的副作用。
   - **核心连戏道具锚（`PROP`）**：凡**跨 ≥ 2 个镜头且至少有 1 次中近景/特写露出**的关键剧情道具，先在中灰底 `#555A64` + 45° 侧光下独立定妆，所有相关空景与首帧统一溯源该图。
   - **核心主角参考干声（`VOICE-REF`）**：为 1–3 位核心主角在开机前各锁定 **1 段 5–10 秒清晰无杂音干声**，绑定即梦角色音色或 `@Audio`“以音锁音”。
   - **独立纯净空景（`SCENE`）**：严格遵循**单空间纯净去耦**、**360° 房间钟面平面拓扑**与**DP 光影六要素**；剧情引起空间状态改变后（如物件移位、桌面留空），下游须切换至新状态定妆图/首帧，严禁继续喂旧状态空景。
3. **本幕增量资产**：新场空景、换装、新道具及本幕全部 S 级首帧按幕补建，写入「一幕一手册」。

### 第 3 步：首帧驱动默认优先（把 90% 不确定性消灭在低成本静态图阶段）
鉴于 **1 条视频返工的积分与时间成本远超 10 张静态图**，全流程默认采用**「首帧即定妆、视频只管演」**策略：

| 分级 | 适用镜头类型 | 制作路径 | 占比参考 |
| :--- | :--- | :--- | :---: |
| **S 级首帧驱动（默认主力）** | ① 抖音前 3 秒开场钩子、情绪高潮、结局定格<br>② 全部人物近景正反打、复杂多人站位、车内透视<br>③ 涉及核心连戏道具（`PROP`）、场景状态变更（`S1`）或特殊俯仰/门洞视角的镜头 | **先在 `Seedream 5.5` 合成 16:9「院线剧照级首帧（`SHOT-START`）」**，静态图审清构图、光比、人物五官服装、道具外观、空间状态与视线轴线后，再以 **`1 张首帧 + 0–1 段干声`** 极简驱动视频；同机位、同坐姿跨段落镜头可直接复用同一张自然放松静态首帧（遵守 `ERR-011`） | **~85%–100%**（Seedance 2.0 推荐全线优先） |
| **A 级多图直出（极少数例外）** | 无严格道具接戏、无状态冲突的极简氛围空镜或宽松过渡镜 | 使用**纯净空景 + 单人图**（严禁重复挂同源 `STYLE-REF`），且正文必须写明人物在空景中的位置、朝向、机位方向与背景露出的具体区域（`ERR-015`） | **~0%–15%** |
| **V 级选配加速** | 极难文字描述的电影级运镜（如环绕/跟推节奏）或克制细腻微表情戏 | 按需挂载 **3–5 秒参考视频（`@Video`）**（对标电影运镜片段或创作者手机自拍表演节奏）做动作/运镜迁移 | 按需 |

> **铁律**：
> 1. 首帧静态图如果“截下来不像电影剧照”或存在道具/状态/视线偏差，**绝不点生成视频**；宁可在 `Seedream 5.5` 里花 2 分钟重抽或局部精修底图，也不在视频阶段反复烧积分返工。
> 2. **硬切双镜拆单镜（Seedance 2.0 稳定性铁律）**：同空间连贯动作保留单条连续生成（防 `ERR-008`）；但本身就是**硬切两个完全不同景别/视角/主体**的镜头（如人物近景硬切俯拍桌面或手部特写），在 Seedance 2.0 下应直接拆为两个独立 S 级首帧单镜，各自锁死第 0 帧，避免后半镜崩坏拖垮整条长视频重抽。

### 第 4 步：模型无关分镜 → 双版本编译 + 双保险红线门禁（站 3 & 站 4）
1. **分镜先定《中间层镜头规格》**（不含 2.0/2.5 专属语法），含 **360° 空间平面拓扑、核心连戏道具清单（`HERO-PROP`）、场景状态轴（`S0/S1`）**、景别、运镜、表演物理微动、光照-皮肤交互、声音设计与**出入点转场方式**。
2. **按目标模型编译纯净视频 Prompt**（`skills/seedance-prompt-writer/`）：
   - 目标为 **Seedance 2.0**：走 `profile-seedance-2.0.md`（镜号 `镜头1/2/3`、4–15s、单镜单一运镜、严禁时间戳、优先 S 级单镜 1–2 素材极简驱动）。
   - 目标为 **Seedance 2.5**：走 `profile-seedance-2.5.md`（连续整数秒 `[0s-4s]`、4–30s、超 4s 拍可复合运镜、支持多关键帧对齐与原生局部编辑延长、推荐 1–5 主体不塞满 50 上限）。
3. **双保险红线门禁（必须先过审再进即梦）**（`skills/prompt-redline-auditor/`）：
   - **第一道（机械确定性）**：运行 `lint_prompt.py --model <2.0|2.5> --file <手册路径>`，0 幻觉清零语法冲突、情绪大词、比喻词、时间断层、`@` 绑定错误与同源环境图重复挂载（`RL-18`）。
   - **第二道（独立语义复核）**：调用**独立子 Agent**（物理隔离创作上下文）按 `redline-checklist.md`（含核心道具溯源 `RL-16` 与参考图状态冲突 `RL-17`）+ `ERROR_PLAYBOOK.md` 输出结构化 `PASS / FAIL` 清单，**只指错、绝不擅自改写文风**。

### 第 5 步：分幕实测验收、零成本急救与剪映电影收口
1. **失败修复优先级（严禁盲目整段重抽）**：
   `剪映后期零成本急救（镜像/二次构图/贴轨修音）` → `Seedance 2.5 原生局部编辑或延长（MOV 输出锁色温）` → `补 S 级 SHOT-START 首帧重跑` → `拆单镜 INSERT 补救` → `整段重生成`。
2. **单次试跑必记实测卡（`05_test_log.md`）**：每次改 Prompt 遵循**迭代医生原则（一次只改 1–2 个变量）**，保留成功部分；遇到新规律或新坑立刻追加至 `docs/ERROR_PLAYBOOK.md`。
3. **资产与 Prompt 变更全局遍历铁律（严禁顾头不顾尾）**：当资产或 Prompt 产出后，**每次修改任何局部内容**（无论是调人物数量、改构图/站位、换道具/状态还是改首帧），必须顺藤摸瓜遍历全链路受影响节点，同步检查并更新：① 《视觉圣经》（`01_visual_bible.md`）与《资产注册表》（`02_asset_registry.md`）；② 可视化分镜包（360° 平面图与连环画分镜）；③ 分幕手册（分镜规格表、生图 Prompt、对应及下游所有视频 Prompt，含 `S0→S1` 派生链、视线与接点动作）；④ 后期备忘录（`04_post_jianying_memo.md`）与实测台账（`05_test_log.md`）。确认无全局冲突后方可出图/出片。
4. **剪映专业版统一收口**（详查 `docs/POST_JIANYING_GUIDE.md`）：粗剪踩节奏 → 声桥（J/L-Cut + 环境底噪贯通切点）→ 统一黑位压实 + 电影 LUT + 10–15% 35mm 细颗粒 → 16:9 嵌入抖音 9:16 黑边包装（上标题 + 下字幕）。

## 三、即梦核心风控与命名铁律（速查）

1. **人脸合规闭环**：写实 AI 人脸与真人脸在外部上传时均可能被风控拦截。坚持 **`Seedream 5.5` 同账号内部生图 → 存入即梦资产库 → `@` 弹窗点选绑定**，彻底杜绝外部写实人像拦截与跨工具画质漂移。
2. **本地资产归档命名**：验收通过的资产图与合格视频定妆静帧必须当场下载落盘，不依赖平台临时缓存。标准命名：`[资产ID]_[中文名]_[状态].png`，分设目录：`01_身份母档`、`02_灰底视频单人图`、`03_独立空景与风格锚`、`04_S级剧照首帧`、`05_道具与定妆截帧`、`06_废弃归档`。
3. **参考图上传顺序与绑定**：按人物首次出场顺序上传参考图并编号绑定；多主体场景严格单人单图，严禁在图片画面中打文字标签。
