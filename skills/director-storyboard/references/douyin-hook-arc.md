# 抖音 1.5–3 分钟情感剧情中视频：钩子与情绪弧线规范

面向抖音 16:9 横屏（竖屏上下黑边封装）情感剧情号，兼顾**前 3 秒完播留存**与**后段院线情绪后劲**。

## 一、前 3 秒黄金冷开场铁律（生死线）

抖音用户划走一条视频只需要 1.5–2 秒。开场严禁慢吞吞摇空镜、介绍背景或人物平和聊天，必须满足：
1. **视觉即时冲突（0–1.5s）**：第一镜就是情绪张力点、反常动作或强对比构图（如深夜餐桌爆发、红着眼把东西推回桌边、紧闭房门前的僵持），且属于 **S 级王牌镜头**，先出电影剧照首帧把质感立住。
2. **听觉即刻抓耳（0–2.5s）**：在画面亮起 1 秒内抛出带强情绪/悬念的第一句核心台词，或清脆极具冲击力的实景动作音（摔碗、急刹、敲门、电话接通）。
3. **上黑边钩子标题咬合**：主标题 ≤ 12 字，直指核心情感反差或命运悬念，与开场画面互为补充而非机械复读。

## 二、1.5–3 分钟情感剧 4 段黄金结构（约 5–7 幕）

| 阶段 | 占比 | 情绪功能 | 常见高完播结构 |
| :--- | :---: | :--- | :--- |
| **1. 倒叙/冷开场钩子** | 15%–20% | 拉满悬念与代入感，留住滑屏用户 | 直接从最扎心的争吵/决定性瞬间切入（留悬念，后段可回环复用 `MASTER`） |
| **2. 现实阻力递进（2–3 次受阻）** | 45%–50% | 叠加现实委屈与压抑，让观众替主角憋一口气 | 每次想迈出一步都被现实/亲情/金钱按回来，阻力逐级升级 |
| **3. 情绪引爆 / 决裂拐点** | 15%–20% | 压抑到顶点后一次性刺破，完成价值翻转 | 往往回扣开场冲突或出现微小却致命的“最后一根稻草”（如 81 元 ETC 电话） |
| **4. 释怀释放 + 尾板金句** | 10%–15% | 给观众情绪出口与转发/评论动机 | 空间由逼仄室内切向开阔自然光，用克制释怀的动作收尾 + 真实感尾板金句 |

## 三、单场戏五要素自检（排镜前必过）

每场戏必须答出以下 5 点，缺项说明剧本注水，先删改再排分镜：
1. **目标**：主角这场戏具体想达成什么？
2. **障碍**：谁或什么现实条件拦住了他？
3. **行动**：他做了什么可见动作去争取？
4. **转折**：结果和预期发生了什么意外偏离？
5. **价值变化**：结束时主角处境/心理比开场更糟还是更好？

## 四、改编项目证据分级标签（严禁混淆原片事实与改编决策）

- `V`：原片可见画面（附时间码）
- `A`：原片独立音轨听辨（区别于屏幕花字）
- `D`：导演/创作者批准的改编决定（如地点、道具、台词本土化替换）
- `H`：待核实推测（排镜前须与用户确认）
- `T`：实际生成测试结论
